# Боевая Система — Thunder Age 1.0

> Пошаговый бой в стиле Limbus Company, адаптированный под сеттинг ThunderAge.
> Ключевые слова: монеты, столкновения, грехи, рассудок, стаггер, ЭГО, накал, позиции, реакции.

---

## Обзор: как работает один бой

```
РАУНД
│
├─ 0. ФАЗА ПОЗИЦИЙ (только первый раунд)
│     Игрок расставляет оперативников — Передний / Задний ряд.
│     Изменить нельзя после первого раунда.
│
├─ 1. ФАЗА СКОРОСТИ
│     Каждый юнит бросает кубики скорости.
│     Результат определяет порядок хода.
│
├─ 2. ФАЗА ПРИКАЗОВ (опционально)
│     Игрок может потратить один из трёх Приказов Командира.
│     Приказ вступает в силу в этом же раунде.
│
├─ 3. ФАЗА ВЫБОРА НАВЫКОВ
│     Для каждого оперативника случайно выдаётся 3 карты из пула.
│     Игрок выбирает 1. Враги выбирают свои навыки.
│
├─ 4. ФАЗА СТОЛКНОВЕНИЙ (Clash)
│     Навыки оперативников и врагов встречаются.
│     Разрешается через броски монет.
│     Пассивно срабатывают: Цепные атаки, Контрудары, Реакции урона.
│
├─ 5. ФАЗА УРОНА
│     Победившие навыки наносят урон и применяют эффекты.
│     Обновляется Боевой Накал.
│
├─ 6. ФАЗА РАССУДКА
│     SP изменяется по итогам раунда.
│     Проверка паники, корни, усиления.
│
└─ 7. ПРОВЕРКА ЗАВЕРШЕНИЯ
      Все враги оглушены / выведены? → Победа.
      Все оперативники в ноке? → Поражение.
```

## 1. Позиции — Передний и Задний ряд

До первого раунда игрок одним кликом распределяет оперативников по двум рядам.
После этого позиции **не меняются** до конца боя.

| Позиция | Что даёт | Ограничение |
|---|---|---|
| **Передний ряд** | Может атаковать любого врага, инициирует столкновения свободно | Первым получает атаки врагов без щита |
| **Задний ряд** | Защищён — враги атакуют его только если Передний ряд пуст или через особые навыки | Может использовать только навыки с пометкой `Дальний` или `Поддержка` |

### Правила позиций

- Минимум **1 оперативник** в Переднем ряду обязателен.
- Если все оперативники Переднего ряда выведены из боя — Задний ряд **автоматически становится Передним**.
- Навыки без пометки `Дальний` / `Поддержка` у оперативника в Заднем ряду **выдаются с −1 монетой**.

### Зачем это важно

Позиционирование не усложняет управление — решение принимается один раз.
Но оно меняет то, как строится команда: хрупкий саппорт в заднем ряду живёт дольше,
тяжёлый боец в переднем — держит удар на себя.

## 2. Скорость и порядок хода

Каждый юнит в начале раунда бросает **кубики скорости**:

- Оперативники бросают диапазон `СКОРОСТЬ_МИН — СКОРОСТЬ_МАКС` (например, 3–6).
- Тот, кто выбросил больше, действует раньше.
- При равенстве: оперативник приоритетнее врага; среди оперативников — левее в интерфейсе.

### Значения скорости

| Класс оперативника | Скорость |
|---|---|
| Стремительный (Рефлекс-билд) | 5–9 |
| Стандартный | 3–6 |
| Тяжёлый (Тело-билд) | 2–4 |

### Скорость и столкновения

Если оперативник быстрее врага — он **первым предлагает навык** в столкновении.
Это даёт тактическое преимущество: можно вынудить врага принять бой на невыгодных условиях.
