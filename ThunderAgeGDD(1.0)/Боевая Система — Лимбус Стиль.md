# Боевая Система — Thunder Age 1.0

> Пошаговый бой в стиле Limbus Company, адаптированный под сеттинг ThunderAge.
> Ключевые слова: монеты, столкновения, грехи, рассудок, стаггер, ЭГО.

---

## Обзор: как работает один бой

```
РАУНД
│
├─ 1. ФАЗА СКОРОСТИ
│     Каждый оперативник и каждый враг бросают кубики скорости.
│     Результат определяет порядок хода в раунде.
│
├─ 2. ФАЗА ВЫБОРА НАВЫКОВ
│     Для каждого оперативника случайно выдаётся 3 карты из пула.
│     Игрок выбирает 1. Враги выбирают свои навыки.
│
├─ 3. ФАЗА СТОЛКНОВЕНИЙ (Clash)
│     Навыки оперативников и врагов встречаются.
│     Столкновение разрешается через броски монет.
│
├─ 4. ФАЗА УРОНА
│     Победившие навыки наносят урон и применяют эффекты.
│
├─ 5. ФАЗА РАССУДКА
│     SP изменяется по итогам раунда.
│     Проверка паники, корни, усиления.
│
└─ 6. ПРОВЕРКА ЗАВЕРШЕНИЯ
      Все враги оглушены / выведены? → Победа.
      Все оперативники в ноке? → Поражение.
```

---

## 1. Скорость и порядок хода

Каждый юнит в начале раунда бросает **кубики скорости**:

- Оперативники бросают `СКОРОСТЬ_МИН` — `СКОРОСТЬ_МАКС` (например, 3–6).
- Тот, кто выбросил больше, действует раньше в этом раунде.
- При равенстве результата: оперативник приоритетнее врага; среди оперативников — тот, кто левее в интерфейсе.

### Почему это важно

Скорость влияет не только на очерёдность, но и на **столкновения**: если оперативник быстрее, он первым «предлагает» навык и может вынудить врага принять бой на невыгодных условиях.

### Значения скорости у оперативников

| Класс оперативника | Скорость |
|---|---|
| Стремительный (Рефлекс-билд) | 5–9 |
| Стандартный | 3–6 |
| Тяжёлый (Тело-билд) | 2–4 |

---

## 2. Пул навыков и выбор

У каждого оперативника есть **пул из 6 навыков** (S1, S2, S3 — три тира, по 2 варианта в каждом, или уникальная компоновка).

### Как работает выдача

1. В начале хода оперативника система случайно выбирает **3 навыка** из пула.
2. Игрок видит три карты и выбирает **одну**.
3. Выбранный навык уходит в «использованные».
4. Когда пул исчерпан — он **полностью сбрасывается** и начинается заново.

> Это значит: мощные навыки будут появляться редко, слабые — часто. Управление ротацией — часть тактики.

### Тиры навыков

| Тир | Обозначение | Сила монет | Типичная роль |
|---|---|---|---|
| Навык 1 | S1 | 2 монеты | Частый, дешёвый, надёжный |
| Навык 2 | S2 | 3 монеты | Средний баланс урона и эффекта |
| Навык 3 | S3 | 4–5 монет | Редкий, мощный, часто с условием |

---

## 3. Монеты — основная механика броска

Каждый навык имеет:
- **Базовую силу** — фиксированное число (например, 5).
- **Монеты** — количество бросков (например, 3 монеты).

### Как считается урон/сила навыка

```
Итоговая сила = Базовая сила + (количество монет, выпавших орлом × Бонус монеты)
```

Пример навыка «Тяжёлый удар»:
- Базовая сила: 5
- Монеты: 3
- Бонус монеты: +3

Если выпало 2 орла из 3: `5 + (2 × 3) = 11`
Если выпало 0 орлов: `5 + 0 = 5`

### Что влияет на вероятность орла

- Базовая вероятность: **50%** (честная монета).
- **Рассудок (SP):** При высоком SP монеты склонены в пользу орла; при низком — решка чаще.
- **Пассивные навыки** оперативника могут добавлять «искажения монеты» (+10% / -10%).
- **Статус-эффекты:** «Дрожь» добавляет штраф, «Ярость» добавляет бонус.

## 4. Столкновение (Clash)

Столкновение — главная тактическая единица боя. Происходит, когда навык оперативника и навык врага направлены на одну цель одновременно.

### Механика столкновения

```
Оба юнита бросают монеты для своих навыков.
Сравниваются итоговые силы.

Если сила оперативника БОЛЬШЕ:
  → Оперативник побеждает раунд столкновения.
  → Навык врага теряет 1 монету.
  → Если у врага монеты кончились → враг проигрывает столкновение полностью.

Если сила врага БОЛЬШЕ:
  → Враг побеждает раунд столкновения.
  → Навык оперативника теряет 1 монету.
```

Столкновение продолжается **раунд за раундом**, пока у одной из сторон не кончатся монеты.

### Победа в столкновении

- Победитель **наносит полный урон** по цели.
- Проигравший **не наносит урон** этим навыком (или наносит только базовый без монет — зависит от навыка).

### Почему это важно

Столкновение можно **выиграть стратегически**:
- Поставить быстрого оперативника против медленного врага → первым предложить сильный S3.
- Использовать дешёвый S1 для «поглощения» слабого навыка врага → сохранить S3 для незащищённого удара.
- Не всегда нужно побеждать в столкновении — иногда выгоднее дать врагу «потратиться» на слабый навык.

## 5. Грехи — система аффинити

Каждый навык и каждый оперативник принадлежат одному из **7 Грехов**. Это не мораль — это стихии боя.

| Грех | Цвет | Образ | Игровая роль |
|---|---|---|---|
| **Гнев** | Красный | Ярость, прямой удар | Высокий урон, агрессия |
| **Жадность** | Жёлтый | Расчёт, накопление | Эффекты, кражи статусов |
| **Уныние** | Синий | Усталость, замедление | Контроль, дебаффы |
| **Чревоугодие** | Зелёный | Поглощение, регенерация | Лечение, стойкость |
| **Зависть** | Бирюзовый | Копирование, мимикрия | Реакции, контратаки |
| **Гордыня** | Белый | Власть, защита | Баффы, щиты, усиление союзников |
| **Похоть** | Фиолетовый | Манипуляция, яд | DoT, ослабление, контроль разума |

### Как грех влияет на бой

1. **Резисты и слабости:** У каждого врага своё распределение `Неуязвим / Нормально / Слабость / Поглощает` по каждому из 7 грехов.
2. **Ресурс греха:** Когда оперативник использует навык с грехом X, он генерирует **1 единицу ресурса X**. Ресурс используется для ЭГО и Резонанса.
3. **Пассивные усиления:** Многие пассивки срабатывают только при определённом рабочем грехе.

---

## 6. Резонанс

**Резонанс** — бонус за использование нескольких навыков одного греха в один раунд.

| Условие | Тип | Эффект |
|---|---|---|
| 2 навыка одного греха в раунде | **Резонанс** | Мощный бонус (зависит от греха) |
| 3 навыка одного греха рядом в очереди | **Абсолютный Резонанс** | Критический бонус + дополнительный эффект |

### Эффекты Резонанса по грехам

| Грех | Резонанс | Абсолютный Резонанс |
|---|---|---|
| Гнев | +2 монеты всем атакующим навыкам этого раунда | Следующий удар игнорирует защиту |
| Жадность | Похитить 1 бафф у выбранного врага | Похитить все баффы, применить к себе |
| Уныние | Наложить «Замедление» на всех врагов (−1 скорость) | Пропустить ход одному врагу |
| Чревоугодие | Восстановить 20% HP наиболее раненому оперативнику | Восстановить HP всей команде |
| Зависть | Скопировать последний навык использованный врагом | Использовать скопированный навык немедленно |
| Гордыня | Дать щит всей команде на 1 раунд | Усилить следующий навык команды ×2 |
| Похоть | Наложить «Яд» на выбранного врага | Наложить «Паника» на врага |

## 7. Система HP и Стаггер

### Пороги Стаггера

У каждого юнита (оперативника и врага) HP делится на **пороговые сегменты**.

```
HP: 100%  [████████████████████] ← Полное HP

Порог 1:   75% HP
Порог 2:   50% HP
Порог 3:   25% HP
```

При пересечении порога юнит получает **Стаггер**:
- Пропускает следующий ход (не может использовать навык).
- Все столкновения в этот ход автоматически проигрывает (его навыки = сила 0).
- Оперативник в Стаггере теряет `20 SP`.

### Стаггер врага

Стаггер врага — окно возможностей:
- Все атаки по Стаггернутому врагу наносят **+50% урона**.
- Некоторые навыки оперативников активируют **спецэффект** только при ударе по Стаггернутому врагу.

> Тактика: намеренно «пробить» порог врага в начале раунда, чтобы вся команда ударила в уязвимое окно.

## 8. Рассудок (SP — Sanity Points)

**SP** — ресурс психического состояния команды. Это не просто хар-ка; это атмосфера боя.

### Что меняет SP

| Событие | Изменение SP |
|---|---|
| Оперативник победил в Столкновении | +2 SP |
| Оперативник нанёс решающий удар | +3 SP |
| Оперативник проиграл Столкновение | −2 SP |
| Оперативник получил Стаггер | −20 SP |
| Оперативник выведен из боя | −30 SP |
| Союзник убит (не нокаут, а смерть) | −50 SP |
| Абсолютный Резонанс | +15 SP |

### Шкала SP и её эффекты

| Диапазон SP | Состояние | Механический эффект |
|---|---|---|
| 45–45 (максимум 45) | **Вдохновение** | Монеты склонены к орлу (+15% вероятность) |
| 25–44 | **Сосредоточенность** | Нейтральный режим, монеты честные |
| 10–24 | **Напряжение** | Монеты склонены к решке (−10% вероятность) |
| 0–9 | **Паника** | Случайный оперативник в начале раунда может нарушить команду |
| Ниже 0 | **Корни (Corrosion)** | Оперативник применяет ЭГО-Корни — неконтролируемое ЭГО, бьёт по всем |

### Паника

При SP 0–9 в начале раунда происходит проверка Паники (`d6`):
- 1–2: Один случайный оперативник атакует ближайшего союзника своим слабейшим навыком.
- 3–4: Один оперативник пропускает ход (прячется).
- 5–6: Ничего не происходит.

## 9. ЭГО

**ЭГО** — личная сверхспособность оперативника. Его уникальное оружие, надетое поверх обычных навыков.

### Структура ЭГО

Каждое ЭГО имеет:
- **Стоимость:** `X единиц ресурса одного или нескольких грехов` (накоплены за раунды)
- **Тип:** Атака / Поддержка / Зона / Трансформация
- **Эффект:** Уникальный, не масштабируется монетами — фиксированный, мощный

### Как использовать ЭГО

1. Игрок накапливает ресурс нужного греха через использование навыков.
2. При наличии достаточного количества ресурса — доступна кнопка ЭГО.
3. ЭГО использует **весь накопленный ресурс** (не часть).
4. После применения ЭГО оперативник не может использовать навыки в этом раунде.

### Уровни ЭГО

| Уровень | Требование | Сила |
|---|---|---|
| **ZAYIN** | 4 ресурса | Полезный, но не решающий |
| **TETH** | 8 ресурса | Мощный, меняет ход боя |
| **HE** | 15 ресурса | Критический, меняет бой целиком |
| **WAW** | 25 ресурса | Экстремальный, редко доступен |

### ЭГО-Корни (Corrosion)

Если SP оперативника падает ниже 0 — он применяет **ЭГО-Корни**:
- Неконтролируем. Атакует ближайшего юнита (союзник или враг).
- Наносит огромный урон.
- SP этого оперативника сбрасывается до 10 после применения.

> ЭГО-Корни — не провал. Это нарративный момент: оперативник сломался. Иногда этого достаточно, чтобы выиграть бой.

---

## 10. Пассивные навыки

У каждого оперативника 2 пассивных навыка:

- **Личный пассив** — всегда активен, связан с личностью персонажа.
- **Поддерживающий пассив** — срабатывает при выполнении условия (например, «при Резонансе Гнева» или «когда союзник получает Стаггер»).

Пассивы не требуют активации — они отслеживают состояние боя и срабатывают автоматически.

## 11. Типы урона и резисты

### Три физических типа

| Тип | Обозначение | Описание |
|---|---|---|
| **Колющий** | ПРК | Игнорирует часть брони |
| **Режущий** | РЖ | Вызывает «Кровотечение» (DoT) |
| **Дробящий** | ДРБ | Снижает защиту цели на 1 раунд |

### Резисты

У каждого юнита для каждого типа урона одно из четырёх состояний:

| Состояние | Эффект |
|---|---|
| **Слабость** | ×2 урон |
| **Нормально** | ×1 урон |
| **Устойчивость** | ×0.5 урон |
| **Поглощение** | Урон восстанавливает HP |

---

## 12. Ключевые статус-эффекты

| Эффект | Тип | Механика |
|---|---|---|
| **Кровотечение** | DoT | Теряет X HP в начале своего хода |
| **Ожог** | DoT | Теряет X HP + −1 монета к навыкам |
| **Яд** | DoT | Умножается каждый ход (×1.5) |
| **Дрожь** | Дебафф | −1 монета ко всем навыкам |
| **Замедление** | Дебафф | −2 к результату броска скорости |
| **Оцепенение** | Контроль | Не может использовать навыки 1 ход |
| **Паника** | Контроль | Использует случайный навык против ближайшего |
| **Щит** | Бафф | Поглощает X урона до конца хода |
| **Ярость** | Бафф | +1 монета ко всем атакующим навыкам |
| **Концентрация** | Бафф | Следующий навык: все монеты — орёл |

## 13. Победа и поражение

### Победа

- Все враги выведены из боя (HP = 0 или Стаггер в нокаут).
- Выполнено особое условие миссии (добраться до точки, спасти NPC и т.д.).

### Поражение

- Все оперативники в нокауте.
- Провалено условие миссии.

### Канон поражения

Поражение — **не перезагрузка**. Последствия:
- Оперативники получают **Раны** (механические штрафы на 2–3 следующие миссии).
- SP всей команды после провала −30 (долгосрочный эффект).
- Сюжетные ветки могут закрыться или открыться.
- **Иногда проиграть — правильный выбор** (нарративная победа при механическом поражении).

## 14. Пример раунда (схематично)

```
Раунд 3. На поле: Эллиот, Тэфи, Йохан vs. Демон-Вергельт (босс) + 2 культиста.

1. СКОРОСТЬ:
   Тэфи 8 / Йохан 5 / Эллиот 4 / Культист А 3 / Вергельт 6 / Культист Б 2

   Порядок: Тэфи → Вергельт → Йохан → Эллиот → Культист А → Культист Б

2. ВЫБОР НАВЫКОВ:
   Тэфи: выдано [Укол яда (S2, Похоть), Тихий удар (S1, Зависть), Дымовая завеса (S1, Уныние)]
   → Игрок выбирает «Укол яда»
   
   Йохан: выдано [Щитовой удар (S2, Гордыня), Отступление (S1, Уныние), Рывок (S1, Гнев)]
   → Игрок выбирает «Щитовой удар»
   
   Эллиот: выдано [Хук (S1, Гнев), Лезвие Знака (S3, Гнев), Медицинский укол (S2, Чревоугодие)]
   → Игрок выбирает «Лезвие Знака»

3. СТОЛКНОВЕНИЕ:
   Вергельт атакует Эллиота навыком «Рёв бездны» (Сила 12, 4 монеты)
   Эллиот использует «Лезвие Знака» (Сила 9, 5 монет)
   
   → Столкновение! Бросок:
   Вергельт: выпало 2 орла из 4 → 12 + (2×4) = 20
   Эллиот: выпало 3 орла из 5 → 9 + (3×3) = 18
   → Вергельт побеждает раунд. Эллиот теряет 1 монету.
   
   Следующий раунд столкновения:
   Вергельт: 12 + (1×4) = 16
   Эллиот (4 монеты теперь): 9 + (4×3) = 21
   → Эллиот побеждает! Вергельт проигрывает столкновение.
   → «Лезвие Знака» наносит урон Вергельту.

4. РЕЗОНАНС:
   Эллиот использовал «Лезвие Знака» (Гнев).
   Проверка: другие навыки этого раунда — Укол яда (Похоть), Щитовой удар (Гордыня).
   Резонанса нет.

5. РАССУДОК:
   Эллиот выиграл столкновение → +2 SP
   Тэфи нанесла урон культисту → +3 SP
   Итого SP команды: было 28 → стало 33
```
