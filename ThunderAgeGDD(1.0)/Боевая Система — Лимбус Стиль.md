# Боевая Система — Thunder Age 1.0

> Пошаговый бой в стиле Limbus Company, адаптированный под сеттинг ThunderAge.
> Ключевые слова: монеты, столкновения, грехи, рассудок, стаггер, ЭГО, накал, позиции, реакции.

---

## Обзор: как работает один бой

```
РАУНД
│
├─ 0. ФАЗА ПОЗИЦИЙ (только первый раунд)
│     Игрок расставляет оперативников — Передний / Задний ряд.
│     Изменить нельзя после первого раунда.
│
├─ 1. ФАЗА СКОРОСТИ
│     Каждый юнит бросает кубики скорости.
│     Результат определяет порядок хода.
│
├─ 2. ФАЗА ПРИКАЗОВ (опционально)
│     Игрок может потратить один из трёх Приказов Командира.
│     Приказ вступает в силу в этом же раунде.
│
├─ 3. ФАЗА ВЫБОРА НАВЫКОВ
│     Для каждого оперативника случайно выдаётся 3 карты из пула.
│     Игрок выбирает 1. Враги выбирают свои навыки.
│
├─ 4. ФАЗА СТОЛКНОВЕНИЙ (Clash)
│     Навыки оперативников и врагов встречаются.
│     Разрешается через броски монет.
│     Пассивно срабатывают: Цепные атаки, Контрудары, Реакции урона.
│
├─ 5. ФАЗА УРОНА
│     Победившие навыки наносят урон и применяют эффекты.
│     Обновляется Боевой Накал.
│
├─ 6. ФАЗА РАССУДКА
│     SP изменяется по итогам раунда.
│     Проверка паники, корни, усиления.
│
└─ 7. ПРОВЕРКА ЗАВЕРШЕНИЯ
      Все враги оглушены / выведены? → Победа.
      Все оперативники в ноке? → Поражение.
```

## 1. Позиции — Передний и Задний ряд

До первого раунда игрок одним кликом распределяет оперативников по двум рядам.
После этого позиции **не меняются** до конца боя.

| Позиция | Что даёт | Ограничение |
|---|---|---|
| **Передний ряд** | Может атаковать любого врага, инициирует столкновения свободно | Первым получает атаки врагов без щита |
| **Задний ряд** | Защищён — враги атакуют его только если Передний ряд пуст или через особые навыки | Может использовать только навыки с пометкой `Дальний` или `Поддержка` |

### Правила позиций

- Минимум **1 оперативник** в Переднем ряду обязателен.
- Если все оперативники Переднего ряда выведены из боя — Задний ряд **автоматически становится Передним**.
- Навыки без пометки `Дальний` / `Поддержка` у оперативника в Заднем ряду **выдаются с −1 монетой**.

### Зачем это важно

Позиционирование не усложняет управление — решение принимается один раз.
Но оно меняет то, как строится команда: хрупкий саппорт в заднем ряду живёт дольше,
тяжёлый боец в переднем — держит удар на себя.

## 2. Скорость и порядок хода

Каждый юнит в начале раунда бросает **кубики скорости**:

- Оперативники бросают диапазон `СКОРОСТЬ_МИН — СКОРОСТЬ_МАКС` (например, 3–6).
- Тот, кто выбросил больше, действует раньше.
- При равенстве: оперативник приоритетнее врага; среди оперативников — левее в интерфейсе.

### Значения скорости

| Класс оперативника | Скорость |
|---|---|
| Стремительный (Рефлекс-билд) | 5–9 |
| Стандартный | 3–6 |
| Тяжёлый (Тело-билд) | 2–4 |

### Скорость и столкновения

Если оперативник быстрее врага — он **первым предлагает навык** в столкновении.
Это даёт тактическое преимущество: можно вынудить врага принять бой на невыгодных условиях.

---

## 3. Пул навыков и выбор

У каждого оперативника **пул из 6 навыков** (S1, S2, S3 — три тира, по 2 варианта).

### Как работает выдача

1. В начале хода система случайно выбирает **3 навыка** из пула.
2. Игрок видит три карты и выбирает **одну**.
3. Выбранный навык уходит в «использованные».
4. Когда пул исчерпан — он **полностью сбрасывается** и начинается заново.

### Монетная память — новая механика

Если навык **трижды подряд** попадал в выдачу, но игрок его не выбирал — при следующем появлении он получает **+1 бонусную монету** (пометка `Застоявшийся`). Бонус сбрасывается при использовании или сбросе пула.

> Это не наказание за «плохой выбор» — это награда за умение видеть момент. Застоявшийся S3 с лишней монетой может решить бой.

### Тиры навыков

| Тир | Обозначение | Монеты | Роль |
|---|---|---|---|
| Навык 1 | S1 | 2 монеты | Частый, надёжный, дешёвый |
| Навык 2 | S2 | 3 монеты | Баланс урона и эффекта |
| Навык 3 | S3 | 4–5 монет | Редкий, мощный, часто с условием |

---

## 4. Монеты — основная механика броска

Каждый навык имеет:
- **Базовую силу** — фиксированное число (например, 5).
- **Монеты** — количество бросков (например, 3 монеты).
- **Бонус монеты** — прибавка за каждый выпавший орёл.

### Формула

```
Итоговая сила = Базовая сила + (орлов × Бонус монеты)
```

Пример — «Тяжёлый удар» (База 5, Монеты 3, Бонус +3):
- 2 орла из 3: `5 + (2 × 3) = 11`
- 0 орлов: `5 + 0 = 5`

### Что влияет на вероятность орла

| Фактор | Эффект |
|---|---|
| Базовая вероятность | 50% |
| Рассудок (SP) высокий | +15% к орлу |
| Рассудок (SP) низкий | −10% к орлу |
| Статус «Дрожь» | −1 монета |
| Статус «Ярость» | +1 монета |
| Статус «Концентрация» | все монеты = орёл |
| Позиция: Задний ряд без `Дальний` | −1 монета |
| Навык «Застоявшийся» | +1 монета |

## 5. Столкновение (Clash)

Столкновение происходит, когда навык оперативника и навык врага направлены на одну цель одновременно.

### Механика

```
Оба юнита бросают монеты.
Сравниваются итоговые силы.

Если сила оперативника БОЛЬШЕ:
  → Навык врага теряет 1 монету.
  → Если у врага монеты кончились → враг проигрывает столкновение полностью.

Если сила врага БОЛЬШЕ:
  → Навык оперативника теряет 1 монету.
  → Если у оперативника монеты кончились → оперативник проигрывает.
```

Столкновение продолжается раунд за раундом, пока у одной стороны не кончатся монеты.

### Победа в столкновении

- Победитель наносит **полный урон**.
- Проигравший **не наносит урон** этим навыком (или только базовый — зависит от навыка).

---

## 6. Цепные атаки

Если **два или более оперативника** атакуют одну и ту же цель в одном раунде — срабатывает цепь.

| Удар в цепи | Бонус |
|---|---|
| 1-й (первый атакующий) | без бонуса |
| 2-й | +1 бесплатная монета |
| 3-й | +2 бесплатные монеты |
| 4-й и далее | +2 монеты + накладывает `Уязвимость` на 1 раунд |

**Бесплатные монеты** добавляются к броску, но не считаются частью навыка — их нельзя потерять в столкновении.

### Почему это работает без лишних кнопок

Игрок просто выбирает цель для каждого оперативника. Если два выбрали одно и то же — цепь срабатывает автоматически. Никакого отдельного ввода.

> Тактика: направить всех на босса в момент его Стаггера — цепь + Стаггер-окно = огромный урон. Но это значит, что никто не прикрывает от атак рядовых врагов.

## 7. Контрудар

Когда оперативник **проигрывает столкновение** — есть шанс рефлекторно ударить в ответ.

```
Шанс контрудара = Скорость_мин оперативника × 5%

Пример: Тэфи (скорость 5–9) → шанс контрудара 25%
        Йохан (скорость 2–4) → шанс контрудара 10%
```

- Контрудар наносит **30% от базовой силы** проигранного навыка.
- Контрудар **не запускает новое столкновение** — это мгновенный укол.
- Контрудар **не зависит от монет** — он всегда попадает, если сработал.

### Зачем это важно

Стремительные оперативники становятся опасными даже при поражении в столкновении.
Враг, который побеждает все клэши у быстрого юнита, всё равно получает порезы.

## 8. Боевой Накал

**Боевой Накал** — общий ресурс команды, шкала от 0 до 100. Не требует управления — меняется автоматически.

### Что заполняет Накал

| Событие | Изменение |
|---|---|
| Победа в столкновении | +5 |
| Контрудар сработал | +3 |
| Цепная атака (3+ в цепи) | +8 |
| Абсолютный Резонанс | +15 |
| Поражение в столкновении | −4 |
| Оперативник получил Стаггер | −10 |
| Оперативник выведен из боя | −20 |

### Пороги Накала и их эффекты

| Накал | Состояние | Автоматический эффект |
|---|---|---|
| 0–29 | **Холодный** | Нет бонусов |
| 30–59 | **Разогрев** | Все монеты +5% к орлу |
| 60–89 | **Горячий** | +5% к орлу, S1-навыки получают +1 монету |
| 90–100 | **Кипение** | +10% к орлу; первый Стаггер врага в раунде даёт +20 SP команде |

> Накал — это атмосфера боя, видимая на экране. Когда шкала пылает — это кинематографический момент. Команда на волне, всё идёт в цепочки, монеты падают орлом.

## 9. Приказы Командира

У игрока есть **3 Приказа** на весь бой. Каждый — одноразовый. Используются в Фазе Приказов, до выбора навыков.

| Приказ | Эффект | Когда использовать |
|---|---|---|
| **Концентрация** | Все оперативники этого раунда атакуют одну цель (ту, что атакует первый в очереди). Цепная атака срабатывает автоматически. | Против босса в Стаггере |
| **Рассредоточиться** | Каждый оперативник атакует отдельную цель. Каждый получает +2 монеты в этом раунде. | Когда врагов много и нужно снести нескольких разом |
| **Прорыв** | Один выбранный оперативник **автоматически выигрывает** следующее столкновение в этом раунде (монеты всё равно бросаются — для расчёта урона, но победитель определён). | Когда нужно гарантированно нанести удар |

### Ограничения

- Нельзя использовать два Приказа в одном раунде.
- Потраченный Приказ не восстанавливается.
- Приказ «Концентрация» не работает, если в команде только 1 активный оперативник.

## 10. Грехи — система аффинити

Каждый навык и оперативник принадлежат одному из **7 Грехов**. Это не мораль — это стихии боя.

| Грех | Цвет | Образ | Игровая роль |
|---|---|---|---|
| **Гнев** | Красный | Ярость, прямой удар | Высокий урон, агрессия |
| **Жадность** | Жёлтый | Расчёт, накопление | Эффекты, кражи статусов |
| **Уныние** | Синий | Усталость, замедление | Контроль, дебаффы |
| **Чревоугодие** | Зелёный | Поглощение, регенерация | Лечение, стойкость |
| **Зависть** | Бирюзовый | Копирование, мимикрия | Реакции, контратаки |
| **Гордыня** | Белый | Власть, защита | Баффы, щиты, усиление союзников |
| **Похоть** | Фиолетовый | Манипуляция, яд | DoT, ослабление, контроль |

### Как грех влияет на бой

1. **Резисты и слабости:** У каждого врага своё распределение `Неуязвим / Нормально / Слабость / Поглощает` по каждому из 7 грехов.
2. **Ресурс греха:** Использованный навык генерирует **1 единицу ресурса** своего греха. Ресурс идёт на ЭГО и Резонанс.
3. **Пассивные усиления:** Многие пассивки срабатывают только при определённом рабочем грехе команды.

## 11. Резонанс и Противорезонанс

### Резонанс

Бонус за использование нескольких навыков **одного греха** в один раунд.

| Условие | Тип | Эффект |
|---|---|---|
| 2 навыка одного греха в раунде | **Резонанс** | Мощный бонус (зависит от греха) |
| 3 навыка одного греха рядом в очереди | **Абсолютный Резонанс** | Критический бонус + доп. эффект + +15 Накала |

#### Эффекты Резонанса по грехам

| Грех | Резонанс | Абсолютный Резонанс |
|---|---|---|
| Гнев | +2 монеты всем атакующим навыкам раунда | Следующий удар игнорирует защиту |
| Жадность | Похитить 1 бафф у выбранного врага | Похитить все баффы, применить к себе |
| Уныние | Наложить «Замедление» на всех врагов | Пропустить ход одному врагу |
| Чревоугодие | Восстановить 20% HP наиболее раненому | Восстановить HP всей команде |
| Зависть | Скопировать последний навык врага | Использовать скопированный навык немедленно |
| Гордыня | Дать щит всей команде на 1 раунд | Усилить следующий навык команды ×2 |
| Похоть | Наложить «Яд» на выбранного врага | Наложить «Паника» на врага |

### Противорезонанс — новая механика

**Противорезонанс** срабатывает, когда в один раунд используются навыки **противоположных грехов**.

#### Пары противоположностей

| Пара | Конфликт |
|---|---|
| Гнев ↔ Уныние | Ярость гасит апатию — и наоборот |
| Гордыня ↔ Зависть | Власть против мимикрии |
| Жадность ↔ Чревоугодие | Накопление против расточительства |
| Похоть стоит особняком | Конфликтует с Гордыней при Абсолютном Резонансе |

#### Что происходит при Противорезонансе

- Оба оперативника, использовавшие конфликтующие навыки, получают **−1 монету** в этом раунде.
- Зато **враг**, затронутый обоими навыками, получает **×2 к длительности** всех статус-эффектов от этих ударов.
- Это осознанный выбор: потерять монету сейчас — удвоить яд/замедление/кровотечение на враге.

## 12. HP и Стаггер

### Пороги Стаггера

У каждого юнита HP делится на **пороговые сегменты**. При пересечении порога — Стаггер.

```
HP: 100%  [████████████████████]

Порог 1:   75% HP  → Лёгкий Стаггер
Порог 2:   50% HP  → Стаггер
Порог 3:   25% HP  → Тяжёлый Стаггер
```

При Стаггере юнит:
- Пропускает следующий ход.
- Автоматически проигрывает все столкновения в этот ход (сила = 0).
- Оперативник в Стаггере теряет **20 SP**.
- Боевой Накал команды падает на **−10**.

### Стаггер-окно врага

Стаггер врага — окно возможностей. Все атаки по Стаггернутому врагу усилены:

| Удар по Стаггернутому | Бонус урона | Доп. эффект |
|---|---|---|
| 1-й удар | +75% | — |
| 2-й удар | +50% | Принудительно применяется статус навыка |
| 3-й удар и далее | +25% | Враг накапливает «Стаггер-стойкость» |

**Стаггер-стойкость:** после третьего удара в окне враг сопротивляется следующему Стаггеру — порог срабатывает на 10% HP позже. Это не защита, а сигнал: добивай быстро или теряй преимущество.

> Тактика: Приказ «Концентрация» + Стаггер-окно = весь урон команды в два хода. Но если растянуть — враг адаптируется.

### Тяжёлый Стаггер (порог 25%)

Когда враг падает за порог 25% — Тяжёлый Стаггер. Дополнительно:
- Длительность Стаггера **2 хода** вместо одного.
- Все цепные атаки по нему в этот период дают +1 бонусную монету сверх стандарта.

## 13. Рассудок (SP)

**SP** — ресурс психического состояния команды. Это не просто характеристика; это атмосфера боя.

### Что меняет SP

| Событие | Изменение SP |
|---|---|
| Победа в столкновении | +2 |
| Решающий удар (последний по врагу) | +3 |
| Абсолютный Резонанс | +15 |
| Боевой Накал достиг «Кипения» | +20 |
| Поражение в столкновении | −2 |
| Оперативник получил Стаггер | −20 |
| Оперативник выведен из боя | −30 |
| Союзник погиб (не нокаут, а смерть) | −50 |

### Шкала SP

| Диапазон | Состояние | Механический эффект |
|---|---|---|
| 45 (максимум) | **Вдохновение** | +15% к орлу на монетах |
| 25–44 | **Сосредоточенность** | Нейтральный режим |
| 10–24 | **Напряжение** | −10% к орлу |
| 0–9 | **Паника** | Проверка Паники в начале каждого раунда |
| Ниже 0 | **Корни** | Оперативник применяет ЭГО-Корни |

### Паника

При SP 0–9 в начале раунда бросается `d6`:

| Результат | Эффект |
|---|---|
| 1–2 | Один случайный оперативник атакует ближайшего союзника слабейшим навыком |
| 3–4 | Один оперативник пропускает ход |
| 5–6 | Ничего не происходит |

## 14. Канализация паники

**Один раз за бой**, когда команда в состоянии «Паника» (SP 0–9), игрок может нажать кнопку **«Канализировать»**.

### Что происходит

1. Один оперативник (игрок выбирает) **выпускает панику наружу**.
2. В этом раунде он получает **+3 бесплатные монеты** ко всем броскам.
3. Его монеты этого раунда имеют вероятность орла **70%** вместо стандартной.
4. После раунда — оперативник **автоматически получает Стаггер**.
5. SP команды после стаггера восстанавливается на **+10** (выброс напряжения).

### Когда это работает

Канализация — не спасение. Это **отчаянный манёвр**:
- Используй его, чтобы нанести критический удар по боссу в Стаггер-окне.
- Или чтобы добить последнего врага, когда команда на грани.

> Нарративно: оперативник на секунду теряет контроль — и именно в этот момент становится страшнее всего.

## 15. ЭГО

**ЭГО** — личная сверхспособность оперативника. Его уникальное оружие, надетое поверх обычных навыков.

### Структура ЭГО

| Параметр | Описание |
|---|---|
| **Стоимость** | X единиц ресурса одного или нескольких грехов |
| **Тип** | Атака / Поддержка / Зона / Трансформация |
| **Эффект** | Уникальный, фиксированный — не масштабируется монетами |

### Как использовать ЭГО

1. Оперативник накапливает ресурс греха через навыки.
2. При достаточном количестве — кнопка ЭГО становится активной.
3. ЭГО использует **весь накопленный ресурс** (не часть).
4. После применения оперативник **не использует навыки** в этом раунде.
5. ЭГО не участвует в Столкновении — это отдельное действие вне клэша.

### Уровни ЭГО

| Уровень | Требование | Сила |
|---|---|---|
| **ZAYIN** | 4 ресурса | Полезный, не решающий |
| **TETH** | 8 ресурсов | Мощный, меняет ход боя |
| **HE** | 15 ресурсов | Критический, меняет бой целиком |
| **WAW** | 25 ресурсов | Экстремальный, редко доступен |

### ЭГО и Боевой Накал

- Применение TETH или выше даёт **+10 Накала**.
- Применение WAW сразу переводит Накал в состояние **«Горячий»** (60), если он был ниже.

### ЭГО-Корни (Corrosion)

Если SP оперативника падает **ниже 0** — он применяет ЭГО-Корни:

- Неконтролируем. Атакует ближайшего юнита (союзник или враг).
- Наносит огромный урон — как TETH, но без прицеливания.
- SP этого оперативника сбрасывается до **+10** после применения.
- Боевой Накал получает **−15** (хаос внутри команды).

> ЭГО-Корни — не провал. Это нарративный момент: оперативник сломался. Иногда этого достаточно, чтобы выиграть бой.

## 16. Пассивные навыки

У каждого оперативника **2 пассивных навыка**. Не требуют активации — отслеживают состояние боя автоматически.

| Тип | Описание |
|---|---|
| **Личный пассив** | Всегда активен, связан с личностью персонажа |
| **Поддерживающий пассив** | Срабатывает при выполнении условия |

### Примеры условий поддерживающих пассивов

- «При Резонансе Гнева — следующий навык игнорирует резист»
- «Когда союзник получает Стаггер — этот оперативник получает +1 монету на 1 раунд»
- «При HP ниже 30% — базовая сила всех навыков +3»
- «Когда Боевой Накал в состоянии Кипения — контрудары этого оперативника наносят 60% вместо 30%»

Пассивы не перегружают управление: игрок **читает состояние**, а не нажимает кнопки.

## 17. Типы урона и резисты

### Три физических типа

| Тип | Обозначение | Базовый эффект |
|---|---|---|
| **Колющий** | ПРК | Игнорирует 25% брони цели |
| **Режущий** | РЖ | Вызывает «Кровотечение» (DoT) |
| **Дробящий** | ДРБ | Снижает защиту цели на 1 раунд |

### Резисты

| Состояние | Эффект |
|---|---|
| **Слабость** | ×2 урон |
| **Нормально** | ×1 урон |
| **Устойчивость** | ×0.5 урон |
| **Поглощение** | Урон восстанавливает HP |

---

## 18. Реакции типов урона

Если два оперативника бьют **одного врага разными физическими типами** в одном раунде — срабатывает реакция. Автоматически, без дополнительного ввода.

| Комбинация | Реакция | Эффект |
|---|---|---|
| Колющий + Дробящий | **Проламывание** | Враг теряет всю броню на 2 раунда |
| Режущий + Колющий | **Рваная рана** | Все стаки Кровотечения на враге удваиваются |
| Дробящий + Режущий | **Сотрясение** | Враг получает −2 к броску скорости в следующем раунде |
| Все три типа в один раунд | **Разрушение** | Все три эффекта выше + враг немедленно получает Стаггер (если HP позволяет порог) |

### Почему это не усложняет управление

Игрок не нажимает отдельную кнопку. Он просто выбирает навыки — если типы совпали нужным образом, реакция происходит сама. Глубина приходит от **чтения состава команды** перед боем: кто бьёт чем, как сочетаются типы.

## 19. Статус-эффекты

### Дебаффы (наносятся врагам)

| Эффект | Механика |
|---|---|
| **Кровотечение** | Теряет X HP в начале своего хода |
| **Ожог** | Теряет X HP + −1 монета к навыкам |
| **Яд** | Умножается каждый ход (×1.5) |
| **Дрожь** | −1 монета ко всем навыкам |
| **Замедление** | −2 к результату броска скорости |
| **Оцепенение** | Не может использовать навыки 1 ход |
| **Уязвимость** | Следующий удар по этому юниту +50% урона |
| **Паника** | Использует случайный навык против ближайшего |

### Баффы (накладываются на оперативников)

| Эффект | Механика |
|---|---|
| **Щит** | Поглощает X урона до конца хода |
| **Ярость** | +1 монета ко всем атакующим навыкам |
| **Концентрация** | Следующий навык: все монеты = орёл |
| **Стойкость** | Следующий Стаггер-порог не срабатывает 1 раз |

### Стак-эффекты

Кровотечение, Ожог и Яд — **стакуются**. Каждое новое наложение добавляет стак, а не заменяет предыдущий. Рваная рана (реакция) удваивает все стаки Кровотечения разом.

## 20. Победа и поражение

### Победа

- Все враги выведены из боя (HP = 0 или Стаггер в нокаут).
- Выполнено особое условие миссии (добраться до точки, спасти NPC и т.д.).

### Поражение

- Все оперативники в нокауте.
- Провалено условие миссии.

### Канон поражения

Поражение — **не перезагрузка**. Последствия:

| Последствие | Механика |
|---|---|
| Оперативники получают **Раны** | Штрафы на 2–3 следующие миссии |
| SP всей команды после провала | −30 (долгосрочный эффект) |
| Сюжетные ветки | Закрываются или открываются |
| Боевой Накал | Сбрасывается в 0 перед следующим боем |

Игра никогда не говорит «попробуй ещё раз». Она говорит: **вот что произошло. Теперь живи с этим.**

> Иногда проиграть — правильный выбор. Нарративная победа при механическом поражении.

## 21. Пример раунда

```
Раунд 3. Поле: Эллиот, Тэфи, Йохан vs. Демон-Вергельт (босс) + 2 культиста.
Боевой Накал: 54 (Разогрев). SP команды: 28.
Позиции: Эллиот и Йохан — Передний ряд. Тэфи — Задний ряд.

─────────────────────────────────────────────
1. ФАЗА ПРИКАЗОВ
   Игрок использует «Концентрация» (1 из 3 Приказов).
   Все оперативники этого раунда атакуют Вергельта.

─────────────────────────────────────────────
2. ФАЗА СКОРОСТИ
   Тэфи 8 / Вергельт 6 / Йохан 5 / Эллиот 4 / Культист А 3 / Культист Б 2
   Порядок: Тэфи → Вергельт → Йохан → Эллиот → Культисты

─────────────────────────────────────────────
3. ФАЗА ВЫБОРА НАВЫКОВ
   Тэфи (Задний ряд): выдано [Укол яда (S2, Похоть, Дальний),
                               Тихий удар (S1, Зависть, Дальний),
                               Дымовая завеса (S1, Уныние, Поддержка)]
   → Игрок выбирает «Укол яда» (Дальний — подходит для Заднего ряда)

   Йохан (Передний): выдано [Щитовой удар (S2, Гордыня, Дробящий),
                               Отступление (S1, Уныние),
                               Рывок (S1, Гнев, Колющий)]
   → Игрок выбирает «Щитовой удар» (Дробящий)

   Эллиот (Передний): выдано [Хук (S1, Гнев, Дробящий),
                                Лезвие Знака (S3, Гнев, Режущий) ← Застоявшийся! +1 монета,
                                Медицинский укол (S2, Чревоугодие)]
   → Игрок выбирает «Лезвие Знака» (Режущий, 5+1=6 монет)

─────────────────────────────────────────────
4. ФАЗА СТОЛКНОВЕНИЙ

   Приказ «Концентрация» активен → все трое бьют Вергельта.
   Цепная атака: Тэфи первая, Йохан +1 бонусная монета, Эллиот +2 бонусных монеты.

   Вергельт атакует Эллиота «Рёвом бездны» (База 12, 4 монеты).
   Эллиот использует «Лезвие Знака» (База 9, 6 монет, Режущий).

   Столкновение, раунд 1:
     Вергельт: 2 орла из 4 → 12 + (2×4) = 20
     Эллиот: 3 орла из 6 → 9 + (3×3) = 18
     → Вергельт побеждает. Эллиот теряет 1 монету (осталось 5).

   Столкновение, раунд 2:
     Вергельт: 1 орёл из 4 → 12 + (1×4) = 16
     Эллиот: 4 орла из 5+2(бонус) = 9 + (4×3) = 21
     → Эллиот побеждает! Вергельт проигрывает столкновение.

   Контрудар: Эллиот проиграл раунд 1.
     Шанс контрудара = 4 (скорость мин) × 5% = 20%
     → Бросок: сработал. Контрудар наносит 30% от базы = 2.7 ≈ 3 урона.

   Реакция типов урона: Йохан бил Дробящим, Эллиот — Режущим.
     → Сотрясение! Вергельт получает −2 к броску скорости в следующем раунде.

─────────────────────────────────────────────
5. ФАЗА УРОНА

   «Лезвие Знака» наносит Режущий урон → накладывает Кровотечение (3 стака).
   Контрудар Эллиота: +3 урона.
   «Укол яда» Тэфи: Яд (1 стак).
   «Щитовой удар» Йохана: урон + снижение защиты Вергельта на 1 раунд.

   Резонанс: Эллиот (Гнев) + Йохан (Гордыня) + Тэфи (Похоть) → нет Резонанса.
   Противорезонанс: Гордыня ↔ Похоть не входят в пары → нет Противорезонанса.

─────────────────────────────────────────────
6. ФАЗА НАКАЛА

   Победа в столкновении: +5
   Контрудар сработал: +3
   Накал: 54 → 62 (переход в «Горячий»!)
   → Автоматический эффект: S1-навыки следующего раунда получат +1 монету.

─────────────────────────────────────────────
7. ФАЗА РАССУДКА

   Эллиот выиграл столкновение: +2 SP
   Тэфи нанесла удар: +3 SP
   SP: 28 → 33 (Сосредоточенность, нейтральный режим)
```
