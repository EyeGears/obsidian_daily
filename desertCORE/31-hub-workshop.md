# Хаб-мастерская корабля

## Назначение

Хаб-мастерская - безопасная локация для обслуживания корабля между выездами.

Игрок заезжает в мастерскую на корабле и выполняет основные действия:

- ремонтирует корабль;
- создает улучшения корабля;
- экипирует улучшения в слоты корабля;
- меняет установленное оружие;
- проверяет готовность к следующему выезду.

## Место в игровом цикле

1. Игрок выезжает в мир.
2. Получает урон и тратит ресурсы.
3. Добывает материалы, детали, оружие и чертежи.
4. Возвращается в хаб-мастерскую.
5. Чинит корабль и меняет билд.
6. Выезжает снова.

## Вход в мастерскую

Игрок попадает в мастерскую:

- при возвращении на базу;
- при заезде в специальный док;
- после завершения миссии;
- после эвакуации при критическом состоянии корабля.

После входа:

- корабль ставится в док;
- управление кораблем отключается;
- открывается интерфейс мастерской;
- показывается текущее состояние корабля.

## Основные разделы

### Ремонт

Раздел для восстановления состояния корабля.

Функции:

- показать здоровье корпуса;
- показать состояние брони;
- показать поврежденные модули;
- выполнить быстрый ремонт;
- выполнить полный ремонт;
- отремонтировать отдельные части корабля.

Типы ремонта:

- **Быстрый ремонт:** восстанавливает корабль до минимально безопасного состояния.
- **Полный ремонт:** полностью восстанавливает корпус, броню и поврежденные системы.
- **Ручной ремонт:** чинит выбранные части корабля отдельно.

Ремонт тратит материалы или валюту.

### Улучшения

Раздел для создания и установки модулей корабля.

Функции:

- показать доступные чертежи;
- показать стоимость создания;
- показать недостающие материалы;
- создать улучшение;
- установить улучшение в слот;
- снять улучшение;
- заменить улучшение.

Типы улучшений:

- корпус;
- броня;
- двигатель;
- энергосистема;
- оружейные системы;
- грузовой отсек;
- сенсоры;
- утилитарные системы.

Примеры улучшений:

| Улучшение | Эффект |
|---|---|
| Усиленная броня | Больше брони, выше вес |
| Экономичный двигатель | Меньше расход топлива |
| Боевой генератор | Больше энергии для оружия |
| Грузовая рама | Больше места для ресурсов |
| Аварийный щит | Краткая защита в бою |

### Слоты улучшений

Корабль имеет ограниченное количество слотов.

Базовые слоты:

- корпусный слот;
- двигательный слот;
- энергетический слот;
- боевой слот;
- утилитарный слот;
- универсальный слот.

Правила:

- улучшение ставится только в подходящий слот;
- некоторые улучшения занимают несколько слотов;
- некоторые улучшения требуют уровень корабля;
- конфликтующие улучшения нельзя установить вместе;
- снятое улучшение остается в инвентаре.

### Оружие

Раздел для выбора оружия корабля.

Функции:

- показать доступное оружие;
- установить оружие в слот;
- снять оружие;
- заменить оружие;
- сравнить параметры оружия;
- проверить требования по энергии и весу.

Параметры оружия:

- урон;
- скорострельность;
- дальность;
- перезарядка;
- расход энергии;
- вес;
- тип боеприпаса;
- эффективность против брони;
- эффективность против групп врагов.

Базовые слоты оружия:

- основной слот;
- дополнительный слот;
- тяжелый слот.

Примеры оружия:

| Оружие | Роль |
|---|---|
| Автопушка | Универсальное оружие |
| Дробовое орудие | Ближний бой |
| Рельсотрон | Пробитие брони |
| Ракетница | Урон по площади |
| Энергетический резак | Урон по слабым точкам |

## Ресурсы

Мастерская использует ресурсы, полученные в выездах.

Ресурсы тратятся на:

- ремонт;
- создание улучшений;
- создание оружия;
- модификацию оружия;
- повышение уровня корабля.

Интерфейс должен показывать:

- текущий запас ресурсов;
- стоимость выбранного действия;
- недостающие ресурсы;
- редкие ресурсы;
- итог после подтверждения действия.

## Интерфейс

Основные вкладки:

1. Ремонт
2. Улучшения
3. Оружие
4. Склад
5. Выезд

На экране мастерской нужно показывать:

- состояние корпуса;
- состояние брони;
- установленные улучшения;
- установленное оружие;
- доступные слоты;
- вес корабля;
- потребление энергии;
- запас топлива;
- ресурсы игрока.

## Проверка перед выездом

Перед выездом игра проверяет:

- корпус выше минимального значения;
- установлено хотя бы одно оружие;
- вес не превышает лимит;
- энергии хватает на установленные системы;
- топлива хватает на маршрут;
- нет конфликтующих улучшений.

Если есть проблема, игра показывает предупреждение.

Примеры предупреждений:

- "Корпус поврежден."
- "Оружие не установлено."
- "Превышен лимит веса."
- "Не хватает энергии."
- "Не хватает топлива."
- "Есть конфликт улучшений."

## MVP

Минимальная версия мастерской:

- вход в мастерскую после выезда;
- экран состояния корабля;
- быстрый ремонт;
- полный ремонт;
- 3-5 улучшений корабля;
- 2-3 слота улучшений;
- 3-4 оружия;
- 2 слота оружия;
- проверка перед выездом.

Можно отложить:

- ручной ремонт секций;
- уровни мастерской;
- сохранение билдов;
- редкие модификации;
- NPC-мастеров;
- сложные конфликты модулей;
- глубокую экономику склада.

## Требования к системе

- Все действия должны показывать цену до подтверждения.
- Игрок должен видеть результат действия до подтверждения.
- Нельзя скрывать причину блокировки действия.
- Замена оружия в мастерской бесплатна, если не задана отдельная экономика.
- Снятие улучшения не уничтожает его.
- Ремонт должен иметь цену, чтобы урон в выезде имел значение.
- Билд корабля должен иметь ограничения по слотам, весу и энергии.

## Итог

Хаб-мастерская нужна для подготовки корабля к следующему выезду.

Основные функции:

- восстановление корабля;
- создание улучшений;
- установка улучшений;
- выбор оружия;
- проверка готовности к маршруту.
