### **2.2. Реакция врагов**

Система ИИ активно ищет игрока:

- враги прочёсывают зоны, проверяют укрытия;
    
- используют командные тактики и взаимодействуют друг с другом;
    
- проявляют контекстные реакции (зовут союзников, замечают пропавших напарников).

Состояния врагов

| Состояние                                                           | Триггеры входа                                 | Поведение                                                                 | Триггеры выхода                                                       |
| ------------------------------------------------------------------- | ---------------------------------------------- | ------------------------------------------------------------------------- | --------------------------------------------------------------------- |
| **Idle (Патруль)**                                                  | Начальное состояние, потеря цели               | Бродит по маршруту, осматривается, разговаривает                          | Замечает шум/визуальный контакт, обнаруживает труп                    |
| **Investigate (Расследование)**                                     | Слабый шум, подозрение, следы игрока           | Идёт к источнику, осматривает окружение, повышает настороженность         | Не найдена угроза → Idle; обнаружен игрок → Alert                     |
| **Alert (Настороженность)**                                         | Явное подозрение, частичный визуальный контакт | Активно ищет игрока, сообщает союзникам                                   | Потеря следа → Search; полный контакт → Combat                        |
| **Search (Поиск)**                                                  | Потеря игрока после Alert/Combat               | Проверяет укрытия, движется по зоне поиска, координирует с группой        | Неудавшийся поиск → Idle; найден игрок → Combat                       |
| **Combat (Бой)**                                                    | Полный визуальный контакт, атака игрока        | Стреляет, бросает гранаты, флангует, использует укрытия, вызывает помощь  | Потеря игрока → Search; игрок скрыт после длительного времени → Alert |
| **Melee (Ближний бой)**                                             | Близкая дистанция, возможность атаки           | Пытается ударить, удержать или захватить игрока                           | Отход игрока → Combat; смерть/оглушение                               |
| **Grapple / Grab (Захват)**                                         | Удалось схватить игрока                        | Удерживает, наносит урон, пытается добить, удерживает до помощи союзников | Игрок вырывается → Melee/Combat; смерть врага                         |
| **Flee (Отступление)**                                              | Враг ранен, боится, подавлен                   | Отходит за укрытие, зовёт поддержку                                       | Восстановление уверенности → Combat                                   |
| **Downed (Нокдаун, только NPC-союзники/человеческие враги иногда)** | Критическое ранение                            | Лежит, медленно ползёт, зовёт на помощь                                   | Добивание; помощь союзников → Recover                                 |
| **Recover (Восстановление)**                                        | Получена помощь союзника                       | Встаёт, возвращается в бой                                                | Завершение анимации → Combat                                          |
| **Dead (Смерть)**                                                   | Получение смертельного урона                   | Переходит в статичное состояние трупа                                     | —                                                                     |
