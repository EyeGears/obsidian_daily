## Зоны экрана — детальное описание

### [A] Верхняя панель

**Слева:**
- Номер текущего раунда
- Имя юнита, чей ход

**Справа — информация о цели (появляется при наведении / выборе):**
- Имя врага
- Полоска HP (цветная, визуально читаемая)
- Активные статус-эффекты (иконки)
- Слабость и сопротивления (элемент)
- Тип демона и цвет (если применимо)

---

### [B] Изометрическое поле боя

Центральная и самая большая область экрана. Камера фиксирована на активном юните, с возможностью свободного вращения.

**Визуальные индикаторы на поле:**

| Элемент | Как отображается |
|---------|-----------------|
| Доступные клетки для хода | Голубая подсветка |
| Зона досягаемости атаки | Красная подсветка |
| Зона действия AoE-приёма | Оранжевый контур |
| Направление юнита (facing) | Стрелка под моделью |
| Укрытие | Иконка щита на клетке |
| Интерактивный объект | Мерцающий контур + иконка [!] |
| Зоны опасности (огонь/газ/яд) | Цветная анимация на клетках |
| Линия прицеливания (LoS) | Пунктирная линия от стрелка к цели |

**Над юнитами:**
- Мини-полоска HP (зелёная / жёлтая / красная)
- Иконки статус-эффектов
- Индикатор направления (стрелка)
- Числа урона при попадании (всплывающие, быстро исчезают)

---

### [C] Таймлайн инициативы

Горизонтальная полоса внизу-центр. Показывает порядок ходов всех юнитов:

- **Зелёный** — юниты игрока (Эллиот)
- **Синий** — напарники
- **Красный** — враги
- **Текущий юнит** — увеличенная рамка с пульсирующим свечением
- При наведении на иконку юнита → подсветка его позиции на поле

---

### [D] Панель персонажа

Находится между таймлайном и рукой карт. Показывает состояние Эллиота:

| Элемент | Формат |
|---------|--------|
| Портрет | Маленькая аватарка слева |
| HP | Полоса + числа (78/100) |
| ОВ (Выносливость) | Ромбы: заполненный = доступен, пустой = потрачен |
| Энергия Знака | Кристаллы: заполненный = доступен |
| Статус-эффекты | Иконки с таймером (число ходов) |
| Уровень крови | Красная капля с процентом (если > 0) |
| Уровень хвори | Зелёная капля (если > 0) |

---

### [E] Рука карт

5 карт, расположенных горизонтально в нижней трети экрана.

**Анатомия одной карты:**

```
┌─────────────┐
│ ⚔ ХУК       │  ← Иконка категории + Название
│             │
│  [Анимация  │  ← Маленькая иллюстрация приёма
│   удара]    │
│             │
│ Урон: 12    │  ← Основной эффект
│ Ближний бой │  ← Дальность
│ Фронт/Фланк│  ← Требования к позиции
│             │
│ ◆◆          │  ← Стоимость ОВ (ромбы)
└─────────────┘
```

**Цветовая кодировка рамки карты:**

| Цвет рамки | Категория |
|------------|-----------|
| Красный | Атака |
| Синий | Защита |
| Зелёный | Перемещение |
| Жёлтый | Поддержка |
| Фиолетовый | Псионика |
| Серый | Предмет |
| Белый с мерцанием | Ситуативная (контекстная) |

**Состояния карт:**
- **Доступна** — яркая, полноцветная
- **Недостаточно ОВ** — затемнённая, с иконкой замка
- **Выбрана** — приподнята вверх, пульсирующий контур
- **Ситуативная** — белый мерцающий край (указывает на контекст)

---

### [F] Кнопки действий

Расположены под рукой карт. Шесть кнопок:

| Кнопка | Действие | Стоимость |
|--------|----------|-----------|
| Переместиться | Показывает доступные клетки, игрок выбирает куда | 1 ОВ |
| Сбросить руку | Удаляет текущие 5 карт, тянет 5 новых | 2 ОВ |
| Пропустить ход | Завершает ход, сохраняя ОВ | 0 ОВ |
| Осмотреть | Свободная камера, информация о юнитах и объектах | 0 ОВ |
| Тактики напарников | Быстрое меню смены тактики для ИИ | 0 ОВ |
| Инвентарь | Открывает инвентарь (применить расходник вне карт) | зависит от предмета |

## Анимация боя

### Последовательность разыгрывания карты

1. Игрок выбирает карту → карта поднимается из руки
2. Игрок выбирает цель / зону → подсветка области
3. Подтверждение → карта «влетает» в поле
4. Анимация приёма (1–2 секунды)
5. Числа урона всплывают над целью
6. Иконки статусов появляются / исчезают
7. Камера возвращается к позиции по умолчанию

### Камера

- **Стандартное положение:** 45-градусный изометрический вид сверху
- **При атаке:** камера приближается к точке столкновения
- **При критическом ударе:** замедление (0.3 сек) + крупный план
- **При нокауте врага:** короткая кинематографическая камера
- **Свободный обзор:** правый стик / правая кнопка мыши — вращение; колёсико — зум
