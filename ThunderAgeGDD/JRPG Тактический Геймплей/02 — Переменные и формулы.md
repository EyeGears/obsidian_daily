# Переменные и формулы

> Все числовые переменные боевой системы Thunder Age JRPG.

---

## Основные атрибуты персонажа

Каждый персонаж (игрок и NPC) описан набором переменных.

### Базовые характеристики (Primary Stats)

| Переменная | Тип | Описание | Базовое значение (Эллиот, ур. 1) |
|------------|-----|----------|----------------------------------|
| `HP` | int | Очки здоровья. При 0 — нокаут | 100 |
| `HP_MAX` | int | Максимальное HP | 100 |
| `STA` | int | Выносливость (Stamina / ОВ). Ресурс для действий | 8 |
| `STA_MAX` | int | Максимальная выносливость | 8 |
| `STA_REGEN` | int | Восстановление ОВ за ход | 4 |
| `MOB` | int | Мобильность — дальность хода в клетках | 4 |
| `INIT` | int | Инициатива — определяет порядок хода | 6 |
| `ARMOR` | int | Броня — поглощает физический урон (фиксированная величина) | 0 |

### Пять основных навыков (из Disco Elysium-подобной системы)

| Переменная | Тип | Описание | Влияние на бой |
|------------|-----|----------|---------------|
| `INTELLECT` | int (1–10) | Интеллект. Наука, Медик, Лирика, Механика, Арсенал | Урон псионики, эффективность лечения, анализ врагов |
| `CHARISMA` | int (1–10) | Харизма. Эмпат, Гвардия, Егерь, Эго, Меланхолия | Эффективность Воодушевления, контроль напарников, провокация |
| `PHYSIQUE` | int (1–10) | Тело. Импакт, Драгун, Кровь, Техника, Рецептор | Физический урон, HP, устойчивость к оглушению |
| `REFLEX` | int (1–10) | Рефлекс. Нерв, Свобода, Речитатив, Троян, Паук | Инициатива, уклонение, контратака, критический шанс |
| `PSIONICS` | int (1–10) | Псионика. История, Мортис, Зверь, Кочевник, Астрал | Сила Знака, псионический урон, резист к аномалиям |

## Боевые переменные юнита

| Переменная | Тип | Описание |
|------------|-----|----------|
| `POSITION_X` | int | Позиция по X на сетке |
| `POSITION_Y` | int | Позиция по Y на сетке |
| `FACING` | enum (N/S/E/W) | Направление, куда смотрит юнит |
| `IS_GROUNDED` | bool | Лежит ли юнит на земле (после подсечки) |
| `IS_HIDDEN` | bool | Скрыт ли юнит (в кустах / невидимость) |
| `IS_BLOCKING` | bool | Стоит ли в блоке (активная защита) |
| `STATUS_EFFECTS[]` | array | Список активных статус-эффектов |
| `BLOOD_LEVEL` | int (0–100) | Уровень крови на персонаже (влияет на «Кровавый удар» и пассивки) |
| `BLIGHT_LEVEL` | int (0–100) | Уровень заражения хворью. При 100 — тяжёлые дебаффы |
| `SIGN_ENERGY` | int (0–20) | Энергия Знака для псионических способностей (только для обладателей Знака) |
| `DEMON_TAINT` | int (0–100) | Уровень демонической скверны. Открывает демонические приёмы, но добавляет нестабильность |

## Переменные приёма (карты)

Каждый приём описан структурой:

```
Ability {
    id: string                  // уникальный идентификатор
    name: string                // название приёма
    category: enum              // ATTACK / DEFENSE / MOVE / SUPPORT / PSIONIC / ITEM / CONTEXTUAL
    sta_cost: int               // стоимость в ОВ (0–6)
    damage_base: int            // базовый урон (0 для неатакующих)
    damage_type: enum           // PHYSICAL / FIRE / ELECTRIC / POISON / BONE / PSIONIC / TRUE
    range: int                  // дальность в клетках (0 = ближний бой)
    area: enum                  // SINGLE / LINE / CONE / CROSS / CIRCLE_1 / CIRCLE_2
    target: enum                // ENEMY / ALLY / SELF / GROUND
    hit_chance_mod: int         // модификатор попадания (-20..+20)
    status_applied: string      // какой статус накладывает (nullable)
    status_duration: int        // длительность статуса в ходах
    knockback: int              // отталкивание в клетках (0 = нет)
    requires_facing: enum       // FRONT / FLANK / BACK / ANY (с какой стороны работает)
    requires_context: string    // контекстное условие (nullable, пр: "NEAR_WALL", "HP_BELOW_30")
    animation: string           // ключ анимации
    sound: string               // ключ звука
    description: string         // текстовое описание для UI
}
```

| Промасленный | `OILED` | Уязвимость к огню (x2 урон) | 2 хода |

## Формулы

### Расчёт урона

```
FINAL_DAMAGE = (ABILITY.damage_base + SCALING_BONUS) * POSITION_MOD * STATUS_MOD - TARGET.ARMOR

где:
    SCALING_BONUS = зависит от damage_type:
        PHYSICAL  → PHYSIQUE * 2
        FIRE      → PSIONICS * 2
        ELECTRIC  → PSIONICS * 2
        POISON    → PSIONICS * 1.5
        BONE      → PHYSIQUE * 1 + PSIONICS * 1
        PSIONIC   → PSIONICS * 2.5
        TRUE      → 0 (игнорирует броню, нет скейла)

    POSITION_MOD:
        Фронт     → 1.0
        Фланг     → 1.25
        Тыл       → 1.5

    STATUS_MOD:
        BERSERK      → 1.3
        INSPIRED     → 1.1
        DEMON_RAGE   → 1.5
        OILED + FIRE → 2.0
        WET + ELEC   → 2.0
        Стандарт     → 1.0

    Минимальный FINAL_DAMAGE = 1 (всегда хотя бы 1 урон)
```

### Расчёт инициативы

```
TURN_ORDER_VALUE = INIT + REFLEX + d6 (бросок кубика)

Персонажи ходят от большего к меньшему.
При равенстве — сначала ходят игроки, потом враги.
```

### Расчёт попадания

```
HIT_CHANCE = 80 + ABILITY.hit_chance_mod + (REFLEX * 2) - TARGET_EVASION

TARGET_EVASION = TARGET.REFLEX * 2 + (IS_HIDDEN? 30 : 0) + (IS_GROUNDED? -20 : 0)

Минимум HIT_CHANCE = 5% (всегда есть шанс попасть)
Максимум HIT_CHANCE = 95% (всегда есть шанс промахнуться)
```

### Расчёт критического удара

```
CRIT_CHANCE = 5 + (REFLEX * 1.5) + (FACING == BACK? 25 : 0) + (IS_HIDDEN? 30 : 0)
CRIT_DAMAGE = FINAL_DAMAGE * 1.5

Максимум CRIT_CHANCE = 60%
```

### Восстановление выносливости

```
STA_AT_TURN_START = min(STA_CURRENT + STA_REGEN, STA_MAX)

Сохранённые ОВ с прошлого хода добавляются.
Пример: STA_MAX = 8, STA_REGEN = 4, потрачено 3 из 8 → осталось 5.
Следующий ход: min(5 + 4, 8) = 8.
```

## Переменные карты боя

| Переменная | Тип | Описание |
|------------|-----|----------|
| `MAP_WIDTH` | int | Ширина карты в клетках (типично 12–20) |

| `CELL[x][y].is_wall` | bool | Стена (непроходимо) |
| `CELL[x][y].is_cover` | bool | Укрытие (бонус к защите от дальних атак) |
| `TURN_NUMBER` | int | Текущий номер раунда |
| `ACTIVE_UNIT_ID` | string | ID юнита, чей сейчас ход |
