# Боевая система — JRPG Tactical

---

## Общая концепция

Бой в Thunder Age JRPG — это **пошаговое тактическое сражение** на изометрической сетке. Игрок управляет только протагонистом (Эллиотом Лэйном), отдавая ему прямые команды. Напарники (максимум 2) действуют автономно по заранее настроенным тактикам (см. [[07 — ИИ напарников и тактики]]).

Бой вдохновлён глубиной Baldur's Gate 3: позиционирование, использование окружения, высот, интерактивных объектов, комбинации элементов и статусов — всё это критически важно для победы.

---

## Инициация боя

| Параметр | Описание |
|----------|----------|
| Триггер | Столкновение с враждебным NPC, сюжетное событие, охота на демона |
| Расстановка | Юниты размещаются на стартовых позициях карты. Позиции зависят от контекста (засада даёт преимущество) |
| Порядок хода | Определяется значением **Инициативы** каждого юнита. Отображается в Timeline внизу экрана |

### Типы начала боя

- **Нормальный** — обе стороны видят друг друга. Стандартная расстановка.
- **Засада (игрок)** — Эллиот подкрался к врагу. Бонус: +2 к Инициативе всей партии, один бесплатный ход протагониста.
- **Засада (враг)** — враги застали игрока врасплох. Штраф: -2 к Инициативе, враги получают один бесплатный ход.
- **Босс-арена** — фиксированная расстановка, уникальная карта, особые правила.

## Структура хода

Каждый ход состоит из **фазы движения** и **фазы действия**. Порядок произвольный — можно сначала ударить, потом отойти.

### Фаза движения

- Игрок перемещает Эллиота по клеткам сетки.
- Стоимость: **1 Очко Выносливости (ОВ)** за ход перемещения, независимо от расстояния (в пределах дальности хода).
- Дальность хода = значение **Мобильность** персонажа (базовая: 4 клетки).
- Некоторые клетки стоят дороже (лужи — +0 но замедление, хрупкий лёд — риск провала, кровавая трава — 1 HP урона при беге).

### Фаза действия

- Игрок выбирает один приём из **руки карт** (5 карт, случайно выбранных из пула 8–12 способностей).
- Каждый приём стоит определённое количество ОВ.
- Можно **сбросить руку** и получить новую за 2 ОВ (неограниченно).
- Можно **пропустить ход**, сохранив оставшиеся ОВ на следующий раунд.

### Фаза реакции (пассивная)

- Если у Эллиота есть пассивные способности (парирование, контратака, уклонение), они могут сработать вне его хода при атаке врага.
- Шанс срабатывания зависит от навыка **Рефлекс** и текущего запаса ОВ.

## Карточная система приёмов

### Как это работает

1. У каждого персонажа есть **пул приёмов** (8–12 карт).
2. В начале хода из пула случайно выбираются **5 карт** — это текущая «рука».
3. Возможны дубликаты, но вероятность мала.
4. **Ситуативные карты** появляются только при выполнении условий:
   - Рядом интерактивный объект → появляется карта взаимодействия
   - HP ниже 30% → шанс появления карты «Самолечение»
   - Враг повернут спиной → карта «Удушение» или «Удар в спину»
   - Рядом стена → карта «Удар от стены»
5. Игрок может **сбросить руку** за 2 ОВ и получить новый набор.

### Категории приёмов

| Категория | Описание | Примеры |
|-----------|----------|---------|
| **Атака** | Прямой урон одной или нескольким целям | Хук, Круговой удар, Гарпун |
| **Защита** | Снижение или отмена входящего урона | Блок, Парирование, Уклонение |
| **Перемещение** | Тактическое передвижение себя или врага | Толчок, Рывок, Перекат, Сальто |
| **Поддержка** | Лечение, баффы, помощь союзникам | Укол обезболивающего, Воодушевление |
| **Псионика** | Сверхъестественные способности (Знаки) | Перемещение во времени, Молниевый клинок |
| **Предмет** | Использование расходников и оружия | Выстрел, Граната, Коктейль Молотова |
| **Ситуативная** | Появляются только при определённых условиях | Швырнуть бочку, Напрыгнуть с возвышенности |

## Позиционирование и окружение

### Направление и фланги

Каждый юнит обращён в одну из 4 сторон. Это критически важно:

| Атака с... | Эффект |
|------------|--------|
| Фронта | Нормальный урон. Враг может блокировать / парировать |
| Фланга (бок) | +25% урона. Шанс блока снижен вдвое |
| Тыла (спина) | +50% урона. Блок невозможен. Открываются особые приёмы |

### Высота

- **Возвышенность:** +20% урона дальнобойных атак, +15% точности, штраф к урону для атакующих снизу.
- **Низина:** -10% к дальнобойному урону, бонус к укрытию.
- **Падение с высоты:** наносит тяжёлый урон (зависит от высоты).

### Интерактивные объекты на поле боя

| Объект | Эффект | Взаимодействие |
|--------|--------|----------------|
| Взрывные бочки | Урон по области 3x3 | Выстрелить / поджечь / толкнуть к врагу |
| Бензин / масло | Лужа на полу | Поджечь → горящая зона. Электричество → оглушение по области |
| Вода | Лужа | Электрическая атака → урон всем в воде |
| Песок | Горстка | Бросить в глаза → Ослепление на 1 ход |
| Высокий куст | Укрытие | Скрытный персонаж может перемещаться невидимо |
| Доска / прут | Импровизированное оружие | Вырвать → усиление ударов / новый мувсет |
| Стул | Метательный | Швырнуть → урон + оглушение |
| Возвышенность | Тактическая позиция | Атака сверху → усиленный урон |
| Дым | Область задымления | Невозможно стрелять сквозь. Снижает точность |
| Дурманящий газ | Область | -2 ОВ за ход всем в зоне |
| Паровой клапан | Ловушка | Перекрыть / направить пар на врага → урон + ожог |
| Шаровая молния | Бродячая | Выстрелить рядом → оглушение по области |

## Система элементов и реакций

Комбинации элементов создают тактические цепочки:

| Комбинация | Результат |
|------------|-----------|
| Огонь + Масло | Горящая зона (3 хода) |
| Электричество + Вода | Оглушение всех в воде |
| Огонь + Грибные споры | Взрыв по области |
| Холод + Споры | Рассеивание, открытие обзора |
| Электричество + Металл | Обезоруживание, усиленный урон |
| Яд + Огонь | Ядовитое облако сгорает, очищая зону |

## Победа и поражение

### Условия победы

- Нокаут всех врагов
- Выполнение особого условия миссии (защитить NPC, дойти до точки, продержаться N ходов)

### Условия поражения

- Нокаут Эллиота (протагонист упал → бой проигран)
- Провал условия миссии (NPC погиб, время истекло)

### Важно: поражение ≠ Game Over

Проигранный бой — это **каноничный исход**. История продолжается, но последствия другие:
- Эллиот получает раны (дебаффы на следующие бои)
- Репутация меняется
- Сюжетные ветки могут закрыться или открыться
- Иногда **выгоднее проиграть** — это осознанная часть дизайна

## Тактические принципы

1. **Управление выносливостью** — мощные приёмы стоят дорого. Иногда лучше сэкономить ОВ на следующий ход.
2. **Позиционирование** — удар в спину даёт +50%. Контроль фланга решает бой.
3. **Окружение** — толчок врага в бочку, лужу, с высоты — чистая тактика.
4. **Управление рукой карт** — сброс за 2 ОВ может спасти ход, но истощает ресурсы.
5. **Комбинации элементов** — масло + огонь, вода + электричество.
6. **Синергия с напарниками** — даже без прямого управления, правильная тактика ИИ критична.
7. **Выбор битвы** — иногда лучше не вступать в бой или проиграть ради нужного сюжета.
