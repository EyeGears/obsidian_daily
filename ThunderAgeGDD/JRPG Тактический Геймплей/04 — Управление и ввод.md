# Управление и ввод

> Как игрок ходит и на какие кнопки нажимает.

---

## Два режима управления

Игра поддерживает управление **геймпадом** и **клавиатурой + мышью**. Управление адаптировано для каждого режима.

---

## Геймпад (PlayStation / Xbox)

### Навигация по полю боя

| Кнопка | Действие |
|--------|----------|
| **Левый стик** | Перемещение курсора по клеткам сетки |
| **Правый стик** | Вращение камеры (4 позиции по 90°) / свободный обзор |
| **L2 / LT** | Зум камеры (приблизить) |
| **R2 / RT** | Зум камеры (отдалить) |

### Действия

| Кнопка | Действие |
|--------|----------|
| **X / A** | Подтвердить выбор (карта, клетка, цель) |
| **O / B** | Отменить / Назад |
| **△ / Y** | Осмотреть (информация о клетке / юните под курсором) |
| **□ / X** | Переместиться (включает режим выбора клетки для хода) |

### Управление рукой карт

| Кнопка | Действие |
|--------|----------|
| **L1 / LB** | Переключить карту влево |
| **R1 / RB** | Переключить карту вправо |
| **X / A** | Выбрать подсвеченную карту → режим прицеливания |
| **L1 + R1 / LB + RB** | Сбросить руку (reshuffle, стоит 2 ОВ) |

### Быстрое меню

| Кнопка | Действие |
|--------|----------|
| **D-pad Вверх** | Открыть меню тактик напарников |
| **D-pad Вниз** | Пропустить ход |
| **D-pad Влево** | Инвентарь |
| **D-pad Вправо** | Журнал боя (лог событий) |
| **Options / Start** | Пауза / Меню |
| **Touchpad / Select** | Показать полную карту поля |

## Клавиатура + Мышь

### Мышь

| Действие мышью | Результат |
|---------------|-----------|
| **Навести на клетку** | Подсветка клетки, показ информации |
| **Навести на юнита** | Всплывающая информация (HP, статусы, слабости) |
| **Навести на карту** | Подробное описание приёма |
| **ЛКМ по карте** | Выбрать приём → режим прицеливания |
| **ЛКМ по клетке (в режиме хода)** | Переместить Эллиота на эту клетку |
| **ЛКМ по цели (в режиме прицеливания)** | Выполнить приём по выбранной цели |
| **ПКМ** | Отмена текущего действия / Свободное вращение камеры |
| **Колёсико** | Зум камеры |
| **СКМ (нажатие колёсика)** | Осмотр юнита под курсором |

### Клавиатура

| Клавиша | Действие |
|---------|----------|
| **1, 2, 3, 4, 5** | Выбрать карту из руки (слева направо) |
| **Q** | Переместиться (включает режим выбора клетки) |
| **E** | Осмотреть юнит / объект |
| **R** | Сбросить руку (reshuffle, 2 ОВ) |
| **Space** | Пропустить ход |
| **T** | Меню тактик напарников |
| **I** | Инвентарь |
| **Tab** | Переключиться между юнитами на таймлайне (для осмотра) |
| **F** | Показать зону досягаемости всех врагов (toggle) |
| **G** | Показать элементальные реакции на поле (toggle) |
| **Ctrl** | Удерживать для просмотра подробной информации при наведении |
| **Esc** | Пауза / Меню |
| **M** | Полная карта поля боя |

### Горячие клавиши камеры

| Клавиша | Действие |
|---------|----------|
| **← →** | Поворот камеры на 90° |
| **↑ ↓** | Наклон камеры |
| **+ / -** | Зум |
| **Home** | Сброс камеры на Эллиота |

## Пошаговый процесс хода игрока

Последовательность действий игрока за один ход Эллиота:

### Шаг 1: Начало хода

```
Ход Эллиота начинается.
→ ОВ восстанавливается: STA = min(STA + STA_REGEN, STA_MAX)
→ Из пула способностей случайно выбираются 5 карт → рука
→ Ситуативные карты проверяются и добавляются
→ Камера центрируется на Эллиоте
→ Раздаётся звуковой сигнал «Ваш ход»
```

### Шаг 2: Оценка ситуации

Игрок может свободно осмотреть поле:
- Навести мышь / стик на любого юнита → информация
- Нажать **F** → увидеть зону досягаемости всех врагов
- Нажать **Tab** → пролистать юнитов на таймлайне
- Нажать **G** → увидеть элементальные зоны

### Шаг 3: Решение — двигаться или атаковать

**Вариант A: сначала движение**
1. Нажать **Q** / **□** → подсветка доступных клеток (голубой)
2. Навести на клетку → информация о местности
3. **ЛКМ / X** → Эллиот перемещается (анимация ходьбы)
4. -1 ОВ
5. Рука карт обновляется (ситуативные карты могут измениться)

**Вариант B: сначала приём**
1. Навести на карту / нажать **1–5** → карта выделяется
2. Прочитать описание → оценить стоимость ОВ
3. **ЛКМ / X** → режим прицеливания:
   - Красная подсветка целей в зоне досягаемости
   - AoE-приёмы показывают зону поражения
   - Процент попадания отображается над целью
4. Выбрать цель → **ЛКМ / X** → подтверждение
5. Анимация атаки → результат

**Вариант C: сброс руки**
1. Нажать **R** / **L1+R1** → текущие 5 карт исчезают
2. -2 ОВ
3. 5 новых карт из пула
4. Можно повторять (если хватает ОВ)

**Вариант D: пропуск**
1. Нажать **Space** / **D-pad Вниз**
2. Оставшиеся ОВ сохраняются на следующий ход
3. Переход к следующему юниту в таймлайне

### Шаг 4: Дополнительные действия

После перемещения и/или приёма (если остались ОВ):
- Можно выполнить ещё одно действие (другую карту, ещё одно перемещение)
- Можно открыть меню тактик напарников (**T / D-pad Вверх**)
- Можно завершить ход досрочно

### Шаг 5: Завершение хода

- Игрок нажимает **Space / D-pad Вниз** или тратит все ОВ
- Переход к следующему юниту по таймлайну
- Если следующий — напарник → ИИ автоматически выполняет ход
- Если следующий — враг → ИИ врага ходит

## Управление между боями (исследование)

### Перемещение по городу

| Кнопка | Действие |
|--------|----------|
| **Левый стик / WASD** | Перемещение Эллиота |
| **X / A / ЛКМ** | Взаимодействие с NPC / объектом |
| **△ / Y / E** | Осмотреть объект |
| **□ / X / Q** | Быстрое использование лечения |
| **Options / Esc** | Меню паузы |
| **I** | Инвентарь |
| **J** | Журнал заданий |
| **P** | Карта города |

### Предбоевая подготовка

Перед началом охоты на демона игрок может:
1. Выбрать напарников (экран формирования отряда)
2. Настроить тактики ИИ для каждого напарника
3. Проверить экипировку и расходники
4. Изучить информацию о задании (тип демона, цвет, рекомендации)

---

## Визуальная обратная связь

| Действие игрока | Визуальный ответ |
|-----------------|-----------------|
| Навести курсор на клетку | Мягкая подсветка, иконка местности |
| Выбрать карту | Карта приподнимается, пульсация рамки |
| Недостаточно ОВ для карты | Карта тускнеет, появляется иконка замка |
| Подтвердить атаку | Звук удара, всплывающие числа, тряска экрана при крите |
| Промах | Звук свиста, текст «ПРОМАХ» над целью |
| Критический удар | Замедление кадра, золотая вспышка |
| Нокаут врага | Мини-катсцена, эффект рассеивания |
| Ход напарника | Камера следит за напарником, показывает его действия |
