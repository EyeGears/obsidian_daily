# ИИ напарников и тактики

> Игрок управляет только Эллиотом. Напарники (до 2) управляются автономным ИИ.
> Поведение ИИ настраивается через систему тактик.

---

## Принцип: Напарники — не марионетки

Напарники — **живые персонажи** со своим характером, мнениями и границами. Игрок не контролирует их напрямую, но может **влиять** на их поведение через:

1. **Тактические пресеты** — общая стратегия поведения
2. **Приоритет целей** — кого атаковать в первую очередь
3. **Позиционное предпочтение** — где стоять на поле
4. **Отношения** — чем лучше отношения с Эллиотом, тем послушнее напарник
5. **Боевой дух** — паника меняет поведение

---

## Тактические пресеты

Игрок выбирает один из четырёх пресетов для каждого напарника. Сменить можно **во время хода Эллиота** (бесплатно, 0 ОВ), нажав **T / D-pad Вверх**.

### AGGRESSIVE (Агрессивный)

| Параметр | Поведение |
|----------|-----------|
| Приоритет | Атака > Перемещение > Защита |
| Движение | Всегда идёт к ближайшему врагу |
| Расход ОВ | Тратит всю выносливость на атаки, не экономит |
| Защита | Использует защитные карты только при HP < 20% |
| Поддержка | Не лечит союзников, не баффает |
| Особенность | Может войти в Берсерк (если есть пассивка) |
| Лучше всего для | Штурмовиков, Тарана, бойцов ближнего боя |

### DEFENSIVE (Защитный)

| Параметр | Поведение |
|----------|-----------|
| Приоритет | Защита > Позиция > Атака |
| Движение | Стоит рядом с Эллиотом (2-3 клетки), закрывает его |
| Расход ОВ | Всегда сохраняет 2+ ОВ для защитных карт |
| Защита | Активно блокирует, парирует, использует Провокацию |
| Поддержка | Лечит Эллиота, если HP < 50% |
| Особенность | Перехватывает атаки, направленные на Эллиота (если рядом) |
| Лучше всего для | Тарана, Мечника, напарников с высоким HP |

### SUPPORT (Поддержка)

| Параметр | Поведение |
|----------|-----------|
| Приоритет | Лечение > Баффы > Позиция > Атака |
| Движение | Держится на 3-4 клетки от врагов, рядом с Эллиотом |
| Расход ОВ | Экономит для лечения и баффов |
| Защита | Уклоняется, отступает при угрозе |
| Поддержка | Лечит самого раненого союзника, баффает перед атакой |
| Особенность | Пополняет патроны, кидает баффы, даёт стимуляторы |
| Лучше всего для | Медика, Поддержки, Инженера |

### BALANCED (Сбалансированный)

| Параметр | Поведение |
|----------|-----------|
| Приоритет | Ситуативно: атака, если HP > 60%; защита, если < 60% |
| Движение | Выбирает оптимальную позицию (укрытие, фланг) |
| Расход ОВ | Тратит 60% на атаку, 40% сохраняет |
| Защита | Блокирует при угрозе, но не перебарщивает |
| Поддержка | Лечит, если кто-то при смерти (< 25% HP) |
| Особенность | Использует элементальные комбо, если видит возможность |
| Лучше всего для | Снайпера, универсальных бойцов |

---

## Приоритет целей

| Пресет | Поведение |
|--------|-----------|
| **NEAREST** | Атакует ближайшего врага |
| **WEAKEST** | Атакует врага с наименьшим HP |
| **STRONGEST** | Атакует врага с наибольшим HP / урон |
| **PLAYER_TARGET** | Атакует того, кого последним атаковал Эллиот |

---

## Позиционное предпочтение

| Пресет | Поведение |
|--------|-----------|
| **FRONTLINE** | Стоит ближе всех к врагу. Перехватывает атаки |
| **MIDLINE** | Держится на средней дистанции (3-4 клетки от врагов) |
| **BACKLINE** | Стоит максимально далеко. Стреляет / поддерживает |

---

## Влияние отношений (COMPANION_RELATIONSHIP)

Отношение напарника к Эллиоту (-100..+100) влияет на качество ИИ:

| Диапазон | Эффект |
|----------|--------|
| **80–100** (Преданность) | Напарник выполняет тактику безупречно. Дополнительные реакции: перехватывает удары за Эллиота, комментирует бой позитивно. +5% ко всем броскам |
| **50–79** (Дружба) | Стандартное поведение. Выполняет тактику стабильно |
| **20–49** (Нейтрально) | Иногда игнорирует приоритет PLAYER_TARGET. Может атаковать другую цель |
| **0–19** (Напряжённость) | Не всегда лечит Эллиота. Может отказаться от тактики DEFENSIVE в критический момент |
| **-50..0** (Неприязнь) | Частые «ошибки» ИИ: атакует не ту цель, тратит ОВ впустую, отказывается от Провокации |
| **-100..-50** (Вражда) | Может покинуть бой. Отказывается выполнять тактики. Возможна агрессия к Эллиоту в сюжетных моментах |

## Боевой дух (COMPANION_MORALE)

Динамический параметр, меняющийся во время боя:

### Повышение морали

| Событие | Бонус |
|---------|-------|
| Эллиот нокаутирует врага | +10 |
| Напарник нокаутирует врага | +15 |
| Эллиот лечит напарника | +5 |
| Критический удар союзника | +5 |
| Эллиот использует Воодушевление | +20 |

### Понижение морали

| Событие | Штраф |
|---------|-------|
| Эллиот получает критический удар | -10 |
| Другой напарник нокаутирован | -20 |
| Напарник горит / отравлен | -5 за ход |
| Аура Страха демона (в радиусе) | -8 за ход |
| Эллиот при смерти (< 15% HP) | -15 |

### Эффекты морали

| Уровень | Эффект |
|---------|--------|
| **80–100** (Боевой подъём) | +10% урон, +10% точность, использует самые сильные приёмы |
| **40–79** (Стабильно) | Нормальное поведение |
| **20–39** (Нервозность) | -10% точность, иногда пропускает оптимальный ход |
| **0–19** (Паника) | Может отступать вместо атаки, использует только защитные карты, может убежать |

## Алгоритм принятия решений ИИ

```
function companion_turn(companion, tactic, battlefield):

    1. ОЦЕНКА УГРОЗ
       - Составить список видимых врагов
       - Оценить расстояние до каждого
       - Определить, кто угрожает Эллиоту

    2. ПРОВЕРКА ВЫЖИВАНИЯ
       if companion.HP < 20%:
           → приоритет: лечение себя / отступление
       if companion.has_status(BURNING / POISONED):
           → если есть лечебная карта — использовать

    3. ПРОВЕРКА ПОДДЕРЖКИ
       if tactic == SUPPORT or tactic == DEFENSIVE:
           if elliot.HP < 50% and companion.has_heal():
               → лечить Эллиота
           if any_ally.HP < 25%:
               → лечить самого раненого

    4. ВЫБОР ПОЗИЦИИ
       target_position = calculate_ideal_position(
           tactic.position_pref,
           enemy_positions,
           elliot_position,
           cover_tiles,
           elevation_tiles
       )
       if current_position != target_position:
           → перемещение (-1 ОВ)

    5. ВЫБОР ЦЕЛИ
       target = select_target(
           tactic.target_priority,
           visible_enemies,
           elliot_last_target
       )

    6. ВЫБОР ПРИЁМА
       best_card = evaluate_hand(
           companion.hand,
           target,
           battlefield_context,
           companion.STA_remaining
       )
       → учитывать элементальные комбо
       → учитывать позиционные бонусы (фланг/тыл)
       → учитывать ситуативные карты

    7. ВЫПОЛНЕНИЕ
       play_card(best_card, target)

    8. СОХРАНЕНИЕ ОВ
       if tactic == DEFENSIVE or tactic == BALANCED:
           → сохранить минимум STA_RESERVE ОВ для защиты
```

## Как напарник реагирует вне своего хода

Напарники могут выполнять **реакции** (если у них достаточно ОВ и есть подходящая пассивка):

| Реакция | Условие | Эффект |
|---------|---------|--------|
| **Перехват** | Враг атакует Эллиота, напарник рядом (1 кл.) | Напарник принимает удар на себя |
| **Контратака** | Враг атакует напарника в ближнем бою | Напарник наносит ответный удар |
| **Предупреждение** | Враг заходит с тыла к Эллиоту | Напарник кричит → Эллиот автоматически разворачивается |
| **Аварийная стрельба** | Враг добегает до Мари (снайпер) | Выстрел в упор с штрафом -20% |

## Комментарии напарников в бою

Напарники **озвучивают** свои действия и реагируют на события:

| Событие | Пример реплики (Крис) | Пример реплики (Мари) |
|---------|----------------------|----------------------|
| Начало боя | *"Опять? Ладно, разберёмся."* | *"Вижу цели. Готова."* |
| Нокаут врага | *"Один готов!"* | *"Снято."* |
| Получение крита | *"Ч-чёрт!"* | *"Задело... терпимо."* |
| Эллиот лечит напарника | *"Спасибо, док."* | *"Я в порядке. Продолжай."* |
| Мораль падает | *"Нас слишком много!"* | *"Отступаем?"* |
| Мораль высокая | *"Давай! Мы можем!"* | *"Отличная работа, Эл."* |
| Напарник нокаутирован | — | *"Крис! Нет!"* |

## Классы напарников и их ИИ-особенности

| Класс | Уникальное поведение ИИ |
|-------|------------------------|
| **Мечник** | Всегда ищет фланг или тыл. Использует Перекат для перепозиционирования |
| **Таран** | При DEFENSIVE — встаёт между Эллиотом и врагами. Использует Провокацию |
| **Снайпер** | Ищет возвышенность. Никогда не идёт в ближний бой добровольно |
| **Штурмовик** | Агрессивно сближается. Использует дробовик на средней дистанции |
| **Поддержка** | Автоматически лечит при HP < 40%. Баффает перед крупными атаками |
| **Инженер** | Ставит мины на пути врагов. Исследует поле (обнаруживает ловушки) |
| **Гренадер** | Атакует AoE-способностями. Избегает союзников в зоне поражения |

## Важно: ИИ не идеален — и это by design

Напарники **намеренно** не играют оптимально. Они:
- Иногда атакуют «не ту» цель (особенно при низких отношениях)
- Могут потратить ОВ на неоптимальный приём
- Реагируют эмоционально (паника, злость, осторожность)
- Комментируют свои решения, объясняя логику

Это создаёт ощущение работы **с живыми людьми**, а не с идеальными автоматами. Ошибки напарников — часть тактики: игрок должен планировать с учётом их несовершенства.
