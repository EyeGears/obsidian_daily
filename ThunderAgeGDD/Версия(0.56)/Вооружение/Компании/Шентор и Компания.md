# Шентор и Компания (Shentor & Co.)

> *"Охота учит одному: в решающий момент у тебя один выстрел. Мы делаем так, чтобы этот выстрел был достаточным."* — Имре Шентор

---

## История компании

**Шентор и Компания** основана в 1871 году **Имре Шентором** — охотником из провинции, который пришёл в город с двумя вещами: самодельным дробовиком и непоколебимой уверенностью в том, что охотничье оружие должно стоить меньше, чем лошадь.

Имре начал с мастерской на окраине Аркады, где чинил чужие ружья и продавал свои. Его дробовики быстро прославились: простые, грубые, невероятно надёжные. К 1890-м годам "Шентор" стал синонимом слова "дробовик" в Либерии.

Второй основатель — **Адель Гершт**, жена Имре и финансовый гений семьи. Именно она превратила мастерскую в компанию, наладила торговую сеть и заключила контракт с Инквизицией на поставку "Агонии" — специального дробовика для охоты на демонов.

После смерти Имре в 1918 году компанию унаследовал их сын **Ференц Шентор** — человек более утончённый, чем отец, но с тем же чутьём к тому, как должен звучать выстрел дробовика.

**Реальный референс:** Ремингтон (Remington) — американская компания, основанная Элифалетом Ремингтоном в 1816 году. Семейный бизнес, ставший гигантом дробовиков. Также отсылка к итальянской Benelli и австрийской Steyr-Mannlicher.

## Конструкторы

### Борис Темников
Пришёл из Инквизиции — бывший оружейный мастер храмовых войск. Создал **"Агонию"** по заказу инквизиторов для охоты на демонов. Калибр 20 — огромный по стандартам ручного оружия. Темников знает, что его дробовик ломает руку стрелку при неправильной стойке. Считает это "естественным отбором среди охотников".

## Модели оружия

### Дробовик "Агония" (Agony)

> Однозарядный дробовик 20 калибра для охоты на демонов. Легенда.

**Референс:** КС-23 (российский карабин специальный, 23 мм — ближайший реальный аналог сверхмощного ручного дробовика) + однозарядный Ithaca M37.

| Параметр | Значение |
|----------|----------|
| Тип | Однозарядный переломный дробовик |
| Калибр | 20 (15.6 мм) — усиленный патрон "Демонобой" |
| Длина ствола | 510 мм |
| Общая длина | 980 мм |
| Масса | 4.2 кг |
| Ёмкость | 1 патрон |
| Дульная энергия | ~4500 Дж |
| Эффективная дальность | 35 м (картечь), 70 м (пуля) |
| Скорострельность | 4–6 выстр/мин (переломка) |
| Принцип действия | Переломный, ручная перезарядка |
| Особенности | Чудовищная отдача (может сломать руку), пробивает демоническую броню, специальный патрон с серебряной картечью |

**Игровые характеристики:**
- Урон: экстремальный
- Скорострельность: крайне низкая
- Точность: средняя (разброс картечи)
- Перезарядка: медленная
- Особенность: бонус урона по демонам и сверхъестественным существам. Риск травмы при низком навыке "Рецептор"

---

### Дробовик Шентор (Shentor-6)

> 6-зарядный помповый дробовик. Рабочая лошадка.

**Референс:** Remington 870 — один из самых массовых помповых дробовиков в мире (производится с 1951 года, более 11 миллионов единиц).

| Параметр | Значение |
|----------|----------|
| Тип | Помповый дробовик |
| Калибр | 12 (18.5 мм) |
| Длина ствола | 470 мм |
| Общая длина | 1010 мм |
| Масса | 3.6 кг |
| Ёмкость | 6 патронов (подствольный трубчатый магазин) |
| Эффективная дальность | 40 м |
| Скорострельность | 15–20 выстр/мин |
| Принцип действия | Помповый (скользящее цевьё) |
| Особенности | Надёжность, простота, возможность дозарядки по одному патрону |

**Игровые характеристики:**
- Урон: высокий
- Скорострельность: средняя
- Точность: средняя ближняя, низкая дальняя
- Перезарядка: поочерёдная (можно дозарядить в процессе)
- Особенность: разные типы патронов (картечь, пуля, зажигательный)

---

### Ружьё Винчестера (Winchester-12)

> 12-зарядное ружьё со скобой Генри. Использует револьверный патрон.

**Референс:** Winchester Model 1873 "The Gun that Won the West" — рычажная винтовка с характерной скобой Генри, символ Дикого Запада.

| Параметр | Значение |
|----------|----------|
| Тип | Рычажная винтовка (скоба Генри) |
| Калибр | .44-40 (револьверный) |
| Длина ствола | 610 мм |
| Общая длина | 1080 мм |
| Масса | 3.3 кг |
| Ёмкость | 12 патронов (подствольный трубчатый магазин) |
| Начальная скорость пули | 390 м/с |
| Эффективная дальность | 150 м |
| Скорострельность | 20–25 выстр/мин (опытный стрелок) |
| Принцип действия | Рычажное (скоба Генри) |
| Особенности | Высокая скорострельность для рычажного оружия, точнее револьвера на дальних дистанциях |

**Игровые характеристики:**
- Урон: средне-высокий
- Скорострельность: высокая (для винтовки)
- Точность: высокая
- Перезарядка: поочерёдная
- Особенность: стилистичная перезарядка скобой, можно стрелять от бедра

## Производство

Завод расположен на **Индустриальном проспекте, 7** (Регистр). Два цеха: ствольный и сборочный. 120 работников. Продукция продаётся открыто через торговую сеть Аркады.
