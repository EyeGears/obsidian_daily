# Крест-Линд Армаментс (Krest-Lind Armaments)

> *"Точность — это не про оружие. Это про того, кто держит его в руках. Мы просто убираем всё, что мешает."* — Эдвард Крест

---

## История компании

**Крест-Линд Армаментс** основана в 1863 году двумя людьми, которые не должны были встретиться: **Эдвард Крест** — отставной офицер колониальных войск, стрелок с репутацией лучшего снайпера полуострова, и **Олаф Линд** — шведский инженер, эмигрировавший в Либерию после банкротства семейной мануфактуры.

Крест знал, чего хочет от оружия. Линд знал, как это сделать. Их первое совместное изделие — **Линейная винтовка Крест-Линд обр. 1865** — стала стандартом точности, который никто не превзошёл в течение двадцати лет. Гвардия заключила контракт на поставку 10,000 единиц. Компания была основана.

К 1880-м годам Крест-Линд расширилась до полной линейки: снайперские винтовки, офицерские револьверы, охотничьи карабины. Их философия: **каждый выстрел — один выстрел**. Массовое автоматическое оружие они считали вульгарным.

После смерти обоих основателей (Крест — 1901, Линд — 1909) компанию возглавил **Генрих Крест**, сын Эдварда — бывший армейский снайпер, человек молчаливый и жёсткий. Под его руководством появился **Ка-50** — снайперская винтовка, ставшая легендой.

**Реальный референс:** Lee-Enfield (британская винтовка, стандарт Империи с 1895 года) + Webley (британские револьверы) + Accuracy International (современные снайперские винтовки). Философия "один выстрел — одно попадание" — классическая британская стрелковая школа.

## Конструкторы

### Генрих Крест
Сын основателя. Служил снайпером в колониальных войнах, потерял левый глаз от осколка. Вернулся и создал **Ка-50** — винтовку, которая "видит лучше, чем два глаза". Одержим идеей идеального выстрела. Тестирует каждый прототип лично. Сотрудники говорят, что он разговаривает с винтовками. Генрих не опровергает.

### Маргарита Линд
Внучка Олафа Линда. Физик-оптик, единственная в Либерии женщина с учёной степенью по прикладной оптике. Разработала телескопический прицел **"Линд-Око"** с переменной кратностью — революция в снайперском деле. Спокойная, ироничная, работает в белом халате среди масляных станков.

### Капитан Эрик Брант
Не конструктор в классическом смысле — полевой офицер, который настолько детально описал требования к идеальной линейной винтовке, что инженеры Крест-Линд воплотили его записи буквально. **Линейная винтовка капитана Бранта** — оружие, созданное по дневнику солдата. Брант погиб в 1918 году, так и не увидев серийный образец.

## Модели оружия

### Снайперская винтовка Ка-50 (Ka-50)

> Болтовая снайперская винтовка. Оружие терпеливых.

**Референс:** Lee-Enfield No. 4 Mk I (T) — снайперская версия легендарной британской винтовки + Mauser 98k Scharfschütze + современная Accuracy International L96.

| Параметр | Значение |
|----------|----------|
| Тип | Магазинная снайперская винтовка |
| Калибр | .456 (11.6 мм) — тяжёлая снайперская пуля |
| Длина ствола | 650 мм |
| Общая длина | 1180 мм |
| Масса (без прицела) | 4.8 кг |
| Масса (с прицелом Линд-Око) | 5.4 кг |
| Ёмкость магазина | 5 патронов (внутренний коробчатый) |
| Начальная скорость пули | 820 м/с |
| Эффективная дальность | 800 м (с прицелом), 400 м (мех. прицел) |
| Скорострельность | 8–12 выстр/мин |
| Принцип действия | Продольно-скользящий затвор (болтовой) |
| Особенности | Исключительная точность, тяжёлый калибр, прицел с переменной кратностью 3–9x |

**Игровые характеристики:**
- Урон: очень высокий
- Скорострельность: низкая
- Точность: исключительная
- Перезарядка: средняя (обойма на 5)
- Особенность: при удержании прицела точность растёт с каждым ходом. Критический урон по голове

### Линейная винтовка капитана Бранта (Brant's Line Rifle)

> Стандартная пехотная винтовка. Надёжная, точная, скучная — как хороший солдат.

**Референс:** Lee-Enfield SMLE Mk III — "десятизарядная" винтовка, стандарт британской армии в обеих мировых войнах. Знаменитый "mad minute" — 15 прицельных выстрелов в минуту.

| Параметр | Значение |
|----------|----------|
| Тип | Магазинная пехотная винтовка |
| Калибр | .456 (11.6 мм) |
| Длина ствола | 640 мм |
| Общая длина | 1130 мм |
| Масса | 3.9 кг |
| Ёмкость магазина | 10 патронов (отъёмный коробчатый) |
| Начальная скорость пули | 744 м/с |
| Эффективная дальность | 500 м |
| Скорострельность | 15–20 выстр/мин (опытный стрелок) |
| Принцип действия | Продольно-скользящий затвор |
| Особенности | Высокая скорострельность для болтовой винтовки, 10-зарядный магазин, штык-нож |

**Игровые характеристики:**
- Урон: высокий
- Скорострельность: средняя (высокая для болтовых)
- Точность: высокая
- Перезарядка: быстрая (обойменная)
- Особенность: штык для ближнего боя, сбалансированное оружие без слабых сторон

### Револьвер Мак (Mac Revolver)

> Армейский револьвер. Прост как кулак, надёжен как смерть.

**Референс:** Webley Mk VI — стандартный армейский револьвер Британской империи + Nagant M1895 (русский армейский револьвер).

| Параметр | Значение |
|----------|----------|
| Тип | Револьвер с переломной рамкой |
| Калибр | .456 (11.6 мм) — тот же, что у винтовки Бранта |
| Длина ствола | 152 мм |
| Общая длина | 286 мм |
| Масса | 1.09 кг |
| Ёмкость барабана | 6 патронов |
| Начальная скорость пули | 190 м/с |
| Эффективная дальность | 45 м |
| Скорострельность | 20–30 выстр/мин |
| Принцип действия | Двойного действия, переломная рамка |
| Особенности | Мгновенная перезарядка (перелом рамки, экстракция всех гильз), останавливающее действие |

**Игровые характеристики:**
- Урон: высокий (для пистолета)
- Скорострельность: высокая
- Точность: средняя
- Перезарядка: быстрая (переломная)
- Особенность: одинаковый калибр с винтовкой Бранта — унификация боеприпасов

### Револьвер Сиф (Sif Revolver)

> Компактный револьвер для скрытного ношения. Последний аргумент джентльмена.

**Референс:** Webley Bulldog — карманный револьвер викторианской эпохи + Smith & Wesson Model 36 "Chief's Special".

| Параметр | Значение |
|----------|----------|
| Тип | Компактный револьвер |
| Калибр | 9×22 "Стандарт" |
| Длина ствола | 63 мм |
| Общая длина | 165 мм |
| Масса | 0.58 кг |
| Ёмкость барабана | 5 патронов |
| Начальная скорость пули | 210 м/с |
| Эффективная дальность | 15 м |
| Скорострельность | 15–20 выстр/мин |
| Принцип действия | Двойного действия |
| Особенности | Крайне компактный, помещается в карман жилета, бесшумный взвод |

**Игровые характеристики:**
- Урон: низко-средний
- Скорострельность: средняя
- Точность: низкая (короткий ствол)
- Перезарядка: медленная (по одному патрону)
- Особенность: скрытное ношение, быстрое извлечение, бонус к инициативе

### Револьвер Ремингтон (Remington-8)

> Тяжёлый боевой револьвер с длинным стволом. Для тех, кто хочет стрелять как из пистолета, но попадать как из винтовки.

**Референс:** Colt Single Action Army ("Миротворец") + Smith & Wesson Model 29 (.44 Magnum — "самый мощный револьвер в мире").

| Параметр | Значение |
|----------|----------|
| Тип | Крупнокалиберный револьвер |
| Калибр | .44-40 (револьверный) |
| Длина ствола | 190 мм |
| Общая длина | 330 мм |
| Масса | 1.24 кг |
| Ёмкость барабана | 8 патронов |
| Начальная скорость пули | 280 м/с |
| Эффективная дальность | 70 м |
| Скорострельность | 18–24 выстр/мин |
| Принцип действия | Двойного действия |
| Особенности | 8-зарядный барабан, длинный ствол, высокая точность, совместимость с патронами Винчестера-12 |

**Игровые характеристики:**
- Урон: средне-высокий
- Скорострельность: средняя
- Точность: высокая (для револьвера)
- Перезарядка: средняя
- Особенность: унификация патронов с Ружьём Винчестера. "Веер" — способность выстрелить все 8 патронов за ход

## Производство

Основной завод — **Королевская оружейная мануфактура Крест-Линд**, расположена в **Редуте**, на **Стрелковом бульваре, 3**. Это старейшее оружейное предприятие Либерии с собственным испытательным полигоном. 200 работников, включая 15 мастеров-оптиков в отдельном цеху. Каждая Ка-50 проходит 48-часовое тестирование перед отгрузкой.
