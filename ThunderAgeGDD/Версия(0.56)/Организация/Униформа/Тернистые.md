# Униформа Тернистых

> *"У нас нет униформы. У нас есть то, что нашли, починили, перешили и надели. И в этом — наша сила: нас нельзя узнать по форме."*

---

## Общее описание

Униформа Тернистых — **не униформа в классическом смысле**. Это набор практичных элементов, объединённых общими принципами: тёмные тона, многослойность, максимум карманов, минимум опознавательных знаков. Каждый Тернистый собирает экипировку сам — из того, что есть.

**Единственный обязательный элемент — красный элемент:** шарф, повязка, нашивка, лента — любой красный акцент, по которому свои узнают своих.

**Референс:** Униформа партизан (испанские герильяс, югославские партизаны) + одежда рабочего класса Европы XIX века + элементы анархистской эстетики. Практичность важнее красоты.

---

## Базовый комплект

### Головной убор
- **Кепка рабочая** — тёмная (серая, коричневая, чёрная). Козырёк — для защиты от дождя и узнаваемости (низко надвинут на глаза).
- **Платок/бандана** — повязывается на лицо при операциях (анонимность).
- Некоторые носят **каски** (трофейные гвардейские, перекрашенные).

### Верхняя одежда
- **Куртка рабочая** — плотная ткань, тёмная, с множеством карманов. Типичная шахтёрская/фабричная куртка, усиленная кожаными вставками на локтях и плечах.
  - **Наружные карманы (4-6):** всё, что может пригодиться — от гаек до гранат.
  - **Внутренние карманы (2-4):** документы (поддельные), деньги, листовки.
- **Бронежилет (самодельный):** у некоторых — стальные пластины, вшитые в подкладку куртки. Тяжело, но спасает от ножа и картечи.

### Пояс и снаряжение
- **Пояс** — кожаный, широкий, часто — армейский (трофей или покупка на чёрном рынке). На поясе:
  - Кобура (если есть пистолет)
  - Нож в ножнах (обязательно — нож у каждого)
  - Фляга
  - Подсумок с патронами / инструментами
  - Сумка на поясе (маленькая)
- **Бандольера** (патронная лента через плечо) — для тех, у кого есть винтовка.

### Штаны и обувь
- **Рабочие штаны** — плотные, тёмные, с карманами на бёдрах. Укреплены кожаными вставками.
- **Ботинки** — тяжёлые рабочие, шнурованные до середины голени. Подошва — толстая, для бега по руинам.

### Плащ/накидка
- **Плащ-палатка** — брезентовая, многофункциональная: плащ, укрытие, носилки, подстилка. Тёмно-серая или хаки.

## Полезные предметы на форме

| Предмет | Расположение | Назначение |
|---------|-------------|------------|
| Нож (большой, универсальный) | Пояс, ножны | Оружие, инструмент, ремонт |
| Отмычки (набор) | Внутренний карман | Вскрытие замков, замена ключей |
| Кремень и трут | Карман штанов | Огонь, сигнальные костры |
| Мел (цветной, 3 шт.) | Карман куртки | Тактические метки на стенах (маршруты, опасности) |
| Зеркальце (маленькое) | Карман куртки | Наблюдение из-за угла, сигнализация |
| Верёвка (8 м, тонкая, прочная) | Через плечо, под курткой | Спуск, подъём, связывание, ловушки |
| Фляга (0.75 л) | Пояс | Вода |
| Аптечка (самодельная) | Поясная сумка | Бинт, спирт, игла с нитью (зашивать раны) |
| Свечной огарок (3 шт.) | Карман куртки | Освещение в руинах и туннелях |
| Листовки (стопка) | Внутренний карман | Пропаганда, информирование |
| Рогатка со стальными шариками | Карман штанов | Бесшумное оружие, отвлечение |
| Проволока (1 м, стальная) | Обмотана вокруг запястья | Ловушки, замки, импровизация |
| Углный карандаш | Карман куртки | Записи, метки, рисунки |
| Свисток (жестяной) | На шее, под курткой | Сигнал тревоги для своих |
| Гвозди (горсть) | Карман штанов | Ловушки для лошадей (разбрасываются при погоне) |
| Еда (сухой паёк) | Внутренний карман | Хлеб, сыр, вяленое мясо |
| Запасные шнурки/бечёвка | Карман | Универсальный крепёж |
| Маска/бандана | Шея / карман | Анонимность, защита от пыли |
| Карта Шрамов (нарисованная от руки) | Внутренний карман | Навигация по руинам, тайные ходы |
| Монета сигнальная (с насечкой) | Карман | Опознавательный знак для своих. Показать — значит "я Тернистый" |

## Знаки различия

У Тернистых нет формальной иерархии, но есть неписаные знаки:

| Знак | Значение |
|------|----------|
| Красный шарф | Боец (стандарт) |
| Красная повязка на руке | Дозорный / часовой |
| Красный крест на рукаве | Медик (не стрелять — даже враги обычно уважают) |
| Терновая ветвь (нашивка) | Ветеран (5+ лет в Тернистых) |
| Два тернистых шипа (нашивка) | Командир звена |
| Волчья голова (нашивка) | Личный отряд Волка |

## Особенности

- **Снайперы (Рита Кукушка):** маскировочная накидка из мешковины с привязанными тряпками и листьями. Бинокль (трофейный)
- **Кузнецы (Маркус Ферр):** кожаный фартук поверх куртки, рукавицы, молоток на поясе
- **Медики (Нина Панцерфауст):** красный крест на рукаве, увеличенная аптечка, скальпель
- **Агитаторы (Ромул Остапов):** больше листовок, меньше оружия, типографская краска на руках
- **Учителя (Лина Моор):** книга и мел вместо оружия, тёплая шаль вместо плаща
