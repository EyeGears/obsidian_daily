# Дом Мейзер (Haus Meyser)

> *"Точность — это уважение к цели."* — девиз компании

---

## История компании

**Дом Мейзер** — старейший оружейный дом Либерии, основанный в 1857 году мастером-оружейником **Клаусом Мейзером** в Редуте, военном квартале города. Клаус был сыном деревенского кузнеца, который ушёл в город с одним набором инструментов и амбициями, превышавшими его рост.

Первые десять лет Мейзер работал в одиночку, изготавливая охотничьи ружья для офицеров Гвардии. Переломный момент — 1867 год: генерал Дитрих Харц заказал партию пистолетов для своего штаба. Клаус создал модель, которая стала легендой — **Мейзер-Фельд** (Meyser-Feld), первый полуавтоматический пистолет с надёжной системой подачи.

После смерти Клауса в 1901 году дело перешло его сыну **Отто Мейзеру**, а затем внуку **Хельмуту Мейзеру** — действующему главе компании. Хельмут — человек противоречивый: гениальный конструктор и отвратительный бизнесмен. Продаёт оружие всем фракциям, утверждая, что "пистолет не имеет политических убеждений".

**Реальный референс:** Маузер (Mauser) — немецкая оружейная компания, основанная братьями Маузер в 1874 году. Знаменита Маузер C96, пистолетом с магазином впереди спусковой скобы и характерной коробчатой рукоятью.

## Конструкторы

### Ирен Буше
Женщина-конструктор — редкость в оружейном деле. Ирен пришла в Дом Мейзер в 1928 году как чертёжница и за шесть лет поднялась до главного инженера. Именно она создала **Мейзер-36** — пистолет, ставший символом военных медиков и радистов. Идея 36-патронного магазина родилась из её наблюдения: медики не могут перезаряжаться в бою, потому что у них заняты руки.

### Вильгельм Кнехт
Мастер ствольного цеха. Бывший часовщик — перешёл в оружейное дело, потому что "точность есть точность, неважно, что ты делаешь". Его стволы отличаются микроскопической точностью нарезки. Кнехт лично проверяет каждый десятый ствол, выходящий с линии.

## Модели оружия

### Мейзер-36 (Meyser-36)

> Пистолет радистов и полевых медиков. 36 патронов в удлинённом магазине.

**Референс:** Маузер C96 "Broomhandle" с увеличенным магазином + Астра М902 (испанский вариант с магазином на 20 патронов).

| Параметр | Значение |
|----------|----------|
| Тип | Самозарядный пистолет |
| Калибр | 9×22 "Стандарт" |
| Длина ствола | 140 мм |
| Общая длина | 312 мм |
| Масса (без патронов) | 1.25 кг |
| Масса (с полным магазином) | 1.72 кг |
| Ёмкость магазина | 36 патронов (съёмный коробчатый) |
| Начальная скорость пули | 425 м/с |
| Эффективная дальность | 50 м |
| Максимальная дальность | 150 м |
| Боевая скорострельность | 30–40 выстр/мин |
| Принцип действия | Отдача ствола с коротким ходом |
| Особенности | Удлинённый магазин, возможность стрельбы с кобурой-прикладом, низкая отдача за счёт веса |

**Игровые характеристики:**
- Урон: низкий за выстрел
- Скорострельность: высокая
- Точность: средняя
- Перезарядка: медленная (длинный магазин)
- Особенность: можно стрелять одной рукой, вторая свободна для медицинских действий

### Мейзер-К9 (Meyser-K9 "Kompakt")

> Компактная версия для скрытого ношения. Популярна у разведчиков и дипломатов.

**Референс:** Маузер HSc — компактный карманный пистолет Маузер 1930-х.

| Параметр | Значение |
|----------|----------|
| Тип | Самозарядный компактный пистолет |
| Калибр | 7.65×17 "Малый" |
| Длина ствола | 86 мм |
| Общая длина | 152 мм |
| Масса (без патронов) | 0.59 кг |
| Ёмкость магазина | 8 патронов |
| Начальная скорость пули | 295 м/с |
| Эффективная дальность | 25 м |
| Боевая скорострельность | 20 выстр/мин |
| Принцип действия | Свободный затвор |
| Особенности | Легко прячется под одеждой, тихий выстрел, слабое останавливающее действие |

**Игровые характеристики:**
- Урон: очень низкий
- Скорострельность: средняя
- Точность: низкая (короткий ствол)
- Перезарядка: быстрая
- Особенность: не обнаруживается при обыске (скрытое оружие)

**Референс:** Маузер C96 в классическом исполнении + Люгер P08 (немецкий армейский пистолет).

| Калибр | 9×22 "Стандарт" |
| Длина ствола | 120 мм |
| Общая длина | 255 мм |
| Масса (без патронов) | 1.05 кг |
| Ёмкость магазина | 10 патронов (внутренний, обойменное заряжание) |
| Начальная скорость пули | 410 м/с |
| Эффективная дальность | 70 м |
| Боевая скорострельность | 25 выстр/мин |
| Принцип действия | Отдача ствола с коротким ходом, рычажное запирание |
| Особенности | Высокая точность, надёжность, кобура-приклад. Символ офицерского состава Гвардии |

**Игровые характеристики:**
- Урон: средний
- Скорострельность: средняя
- Точность: высокая
- Перезарядка: средняя (обойменное)
- Особенность: бонус к точности при стрельбе с кобурой-прикладом

| Масса (без патронов) | 1.35 кг |
| Ёмкость магазина | 10 патронов |
| Начальная скорость пули | 480 м/с |
| Эффективная дальность | 150 м |
| Боевая скорострельность | 20 выстр/мин |
| Принцип действия | Отдача ствола с коротким ходом |
| Особенности | Съёмный деревянный приклад, оптический прицел, использование как лёгкого карабина |

**Игровые характеристики:**
- Урон: средне-высокий
- Скорострельность: низкая (прицельная)
- Точность: очень высокая (с прикладом)
- Перезарядка: средняя
- Особенность: функционирует как лёгкая снайперская винтовка

## Производство

Завод Дома Мейзер расположен в Редуте, на **улице Маршалов, 42**. Три цеха: ствольный (мастер Кнехт), сборочный и испытательный. Работают около 200 человек. Продукция поставляется Гвардии по контракту, но продаётся всем фракциям через торговую сеть.
