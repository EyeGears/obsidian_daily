# Echosystem — диздок (разделённый)

Этот диздок разделён на профильные разделы. Каждый раздел ссылается на остальные, чтобы можно было быстро переходить между решениями по реализации, визуалу, механикам и нарративу.

## Разделы
- [[echosystem/Код.md|Код]] — техническая архитектура, сетевой слой, данные, инструменты, MVP-план реализации.
- [[echosystem/Арт.md|Арт]] — визуальный стиль, биомы, UI-направление, VFX/SFX-настроение.
- [[echosystem/Геймдизайн.md|Геймдизайн]] — core loop, персонажи, оружие, модули, кооператив и босс-фазы.
- [[echosystem/Сюжет.md|Сюжет]] — мир, завязка, фракции, арки персонажей и структура прогрессии по актам.

## Карта связей
- Код реализует системы из [[echosystem/Геймдизайн.md|геймдизайна]] и поддерживает сценарные события из [[echosystem/Сюжет.md|сюжета]].
- Арт визуализирует состояния систем из [[echosystem/Код.md|кода]] и читабельность боёв из [[echosystem/Геймдизайн.md|геймдизайна]].
- Геймдизайн опирается на лор и мотивацию из [[echosystem/Сюжет.md|сюжета]], а также ограничения из [[echosystem/Код.md|кода]].
- Сюжет использует художественные решения из [[echosystem/Арт.md|арта]] и механические крючки из [[echosystem/Геймдизайн.md|геймдизайна]].
