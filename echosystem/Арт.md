# Echosystem — Арт

Связанные разделы: [[echosystem/Геймдизайн.md|Геймдизайн]] · [[echosystem/Сюжет.md|Сюжет]] · [[echosystem/Код.md|Код]] · [[echosystem/dizdoc.md|Хаб диздока]]

## Визуальный столп
- Тон: «страшно-смешно» — хоррор-фактуры + абсурдные контрасты.
- Читаемость с дистанции: силуэты врагов, яркие акценты интерактивных объектов.
- Контраст локаций: уютные хабы против деформированных аномальных зон.

## Художественные ориентиры
- Цвет и чистая читаемость форм в духе приключенческого stylized-подхода.
- Гротеск существ и «телесный сюрреализм» для Эхо-Шума.
- UI/иконки с «радио-сканерной» графикой: шум, рябь, резонанс.

## Локации и биомы
1. **Петля-13 (хаб)**
   - Тёплый свет, «ручная» инженерия, следы постоянного ремонта.
2. **Осколочные поля**
   - Яркая дневная палитра, открытые пространства, дальняя видимость.
3. **Ночные аномалии**
   - Контрастные тени, локальные источники света, вязкий туман.
4. **Босс-арены**
   - Символические декорации, где тема босса читается с первого взгляда.

## Персонажи и враги
- Проводники: утилитарные костюмы, модульная экипировка, считываемые роли по силуэту.
- Враги Эхо-Шума: сочетание «человеческого остатка» и искажённой эмоции.
- Босс «Ретранслятор-Мамонт»: индустриальная масса + «радио-сердце» в ядре.

## VFX / SFX-настроение
- VFX: резонансные кольца, цифровой «срыв», импульсные вспышки узлов связи.
- SFX: радиопомехи, «голоса прошлого», сломанные джинглы в боях с боссом.

## Арт-пайплайн
- Для каждого врага: silhouette-sheet → color keys → combat readability pass.
- Для каждой арены: moodboard + ключевой кадр + шейдерные ограничения по производительности (см. [[echosystem/Код.md|Код]]).
