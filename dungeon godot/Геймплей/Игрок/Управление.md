# Контроллер персонажа (Hyper Light Drifter-style)

## 🧠 Цель

Создать отзывчивую и плавную систему управления для персонажа, включающую:

- Движение в восьми направлениях
    
- Рывок (dash)
    
- Ближнюю атаку
    
- Использование энергии для дальних атак
    
- Взаимодействие с окружением
    

---

## 🧍‍♂️ Состояния персонажа

|Состояние|Описание|
|---|---|
|**Idle**|Персонаж стоит, может поворачиваться, но не двигается.|
|**Move**|Активное движение по направлению входного вектора.|
|**Dash**|Быстрый рывок, дающий неуязвимость и ускорение.|
|**Attack**|Выполняется удар мечом, блокирует движение на короткое время.|
|**Cast / Shoot**|Выполняется дальняя атака с затратой энергии.|
|**Hit / Stagger**|Персонаж получает урон, временно теряет контроль.|
|**Dead**|Персонаж погибает, управление отключено.|

## 🎮 Входные данные (Input)

|Действие|Вход|Описание|
|---|---|---|
|`Move`|Вектор из клавиш (WASD / Stick)|Направление движения.|
|`Attack`|ЛКМ / Кнопка A|Запускает ближнюю атаку.|
|`Dash`|Пробел / RB|Рывок в текущем направлении движения.|
|`Shoot`|ПКМ / RT|Стреляет при наличии энергии.|
|`Interact`|E / X|Взаимодействие с объектами.|

## ⚙️ Переменные контроллера

|Имя|Тип|Описание|
|---|---|---|
|`move_speed`|float|Базовая скорость движения.|
|`acceleration`|float|Ускорение при старте движения.|
|`dash_speed`|float|Мгновенная скорость во время рывка.|
|`dash_duration`|float|Длительность рывка.|
|`dash_cooldown`|float|Время до следующего рывка.|
|`attack_cooldown`|float|Время между ударами.|
|`attack_range`|float|Радиус поражения атаки.|

## 🚶‍♂️ Алгоритм движения

**1. Ввод движения**

- Считать направление `input_dir` из осей ввода.
    
- Если `input_dir` ≠ (0,0):  
    → `direction = input_dir.normalized()`  
    → увеличить `velocity` в этом направлении с учётом `acceleration`.
    
- Если `input_dir` = (0,0):  
    → применить замедление `velocity *= friction`.
    

**2. Ограничение скорости**

- `velocity` не должна превышать `move_speed`.
    

**3. Обновление позиции**

- `position += velocity * delta_time`.
    

---

## ⚡ Рывок (Dash)

**Условия активации:**

- Кнопка `Dash` нажата.
    
- Прошло достаточно времени после последнего рывка (`current_time - last_dash_time > dash_cooldown`).
    

**Процесс:**

1. Устанавливается `is_dashing = true`.
    
2. `velocity = direction * dash_speed`.
    
3. `is_invincible = true` на `dash_duration`.
    
4. После окончания `dash_duration`:
    
    - `is_dashing = false`,
        
    - `is_invincible = false`,
        
    - `velocity` плавно возвращается к нормальной.
        
5. `last_dash_time` обновляется.
    

**Эффекты:**

- Визуальный след (trail).
    
- Звук и вспышка.
    
- Возможность пролетать сквозь врагов или пули (если задано).
    

---

## ⚔️ Атака (Melee)

**Условия:**

- Игрок не в состоянии Dash или Stagger.
    
- Прошёл `attack_cooldown`.
    

**Процесс:**

1. `state = Attack`.
    
2. Игрок останавливается (`velocity = 0`).
    
3. В радиусе `attack_range` проверяются враги в направлении `direction`.
    
4. Применяется урон `attack_damage`.
    
5. При попадании восстанавливается немного `energy`.
    
6. После завершения анимации → `state = Idle`.
    

**Комбо-система (опционально):**

- Если в течение `combo_window` нажата атака повторно → следующая стадия `combo_stage + 1`.
    

---

## 🔫 Дальняя атака (Shoot / Cast)

**Условия:**

- `energy >= cost`.
    
- Игрок не Dash/Attack.
    

**Процесс:**

1. `energy -= cost`.
    
2. Создаётся снаряд в позиции `player_position + direction * offset`.
    
3. Снаряд движется со скоростью `projectile_speed` и наносит `projectile_damage`.
    

---

## ❤️ Получение урона

**Если `is_invincible == false`:**

1. `health -= damage`.
    
2. Включается короткая неуязвимость (`invincible_time`).
    
3. `state = Hit`.
    
4. Игрок немного отбрасывается.
    
5. Если `health <= 0` → `state = Dead`.

## ✨ Особенности в стиле HLD

- **Инерция** — движение немного скользящее, но отзывчивое.
    
- **Dash cancel** — часть атак можно прервать рывком.
    
- **Energy loop** — энергия восстанавливается за успешные удары.
    
- **Feedback** — каждый ввод сопровождается экранным откликом (вспышки, тряска, эффекты).
    
- **Glitch эффект** — при малом здоровье экран искажается.
