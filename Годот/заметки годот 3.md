👉 **Autoload = глобальный объект, который всегда существует и доступен отовсюду.**

---

# 🔥 Для чего используют autoload?

Autoload обычно применяют для:

### ✔ Глобальные переменные

Например — здоровье игрока, текущий уровень, настройки.

### ✔ Глобальные менеджеры

- AudioManager
    
- GameManager
    
- Inventory
    
- SaveSystem
    
- DialogueManager
    

### ✔ Хранение состояния игры

### ✔ Общий доступ к функциям

Проще вызвать:

`Game.play_sound("hit")`

чем искать нужный узел в сцене.

---

# 📌 Как работает autoload?

Когда ты добавляешь скрипт в Autoload:

1. Godot создаёт singleton с указанным именем.
    
2. Этот singleton существует **всё время, пока игра запущена**.
    
3. Ты можешь обратиться к нему **по имени как к глобальной переменной**.
    

Например, если ты добавил `global.gd` с именем `Global`, то можно написать:

`Global.score += 1 Global.save_game()`

и не использовать `get_node()`.

---

# 📁 Где включить autoload?

**Project → Project Settings → Autoload**

Там можно выбрать:

- путь к скрипту или сцене
    
- имя singleton
    
- включить/выключить
    

---

# ✨ Пример простого autoload

### Файл: `global.gd`

`extends Node  var coins = 0  func add_coin():     coins += 1`

В autoload добавляешь этот файл как `Global`.

Теперь в любом скрипте игры:

`Global.add_coin() print(Global.coins)`
