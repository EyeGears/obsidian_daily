# Арт

## Визуальный вектор
- Тёмный неон + академическая архитектура + криминалистическая стерильность.
- Контраст «школьная повседневность» vs «цифровой кошмар расследования».
- UI в стиле голографической сетки: узлы, трассы, зоны риска.

## Ключевые арт-столпы
1. **Детективная читаемость**: улики и интерактивные объекты всегда визуально различимы.
2. **Психологическое напряжение**: цветовые всплески при лжи, угрозе, дедуктивном прорыве.
3. **Инфосистема взлома**: отдельный визуальный язык для сетевого режима (hex-grid, анимированные трассировки).

## Цветовые состояния интерфейса
- `ui_state_safe`: холодный синий
- `ui_state_suspicious`: янтарный
- `ui_state_danger`: красный
- `ui_state_breakthrough`: фиолетово-белый импульс

## Производственный пакет
- Набор иконок типов улик
- Карточки персонажей (портрет + эмоции)
- UI-макеты для: осмотра, взлома, доски дедукции, суда
- VFX: скан, захват узла, обнаружение лжи, «разбитая версия правды»
