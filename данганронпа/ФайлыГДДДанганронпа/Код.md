# Код

## Цель системного слоя
Реализовать детективный геймплей в стиле «сетевая инфильтрация + анализ улик»: игрок взламывает цифровые узлы, собирает фрагменты данных и строит доказательные цепочки для обвинения.

## Основные системы
1. **Investigation Loop**
   - Осмотр сцены
   - Сбор улик
   - Взлом защищённых терминалов
   - Сопоставление улик в логической доске
   - Формирование обвинительного пакета
2. **Hacking Grid**
   - Узлы сети с уровнями защиты
   - Маршрутизация сигнала (ограниченный ресурс времени/фокуса)
   - Риск тревоги при ошибках
3. **Evidence Graph**
   - Улики, свидетели, таймлайн, мотивы
   - Веса достоверности
   - Противоречия и подтверждения
4. **Trial Resolver**
   - Подсчёт силы аргумента
   - Проверка на ложные выводы
   - Ветки исходов дела

## Набор переменных (data model)

### Прогресс игрока
- `player_investigation_rank: int`
- `player_focus_max: int`
- `player_focus_current: int`
- `player_stress: float (0..100)`
- `player_reputation: float (-100..100)`
- `player_intuition: int`
- `player_tech_skill: int`
- `player_rhetoric_skill: int`

### Состояние дела
- `case_id: string`
- `case_stage: enum {scene_scan, interrogation, hack, synthesis, trial}`
- `case_timer_minutes_left: int`
- `case_heat_level: float (0..1)`
- `case_truth_threshold: float (0..1)`
- `case_false_leads_count: int`

### Улики
- `evidence_id: string`
- `evidence_type: enum {physical, digital, testimony, forensic}`
- `evidence_quality: float (0..1)`
- `evidence_integrity: float (0..1)`
- `evidence_reliability: float (0..1)`
- `evidence_chain_of_custody: bool`
- `evidence_tags: string[]`
- `evidence_discovered: bool`

### Связи и логика
- `link_source_evidence_id: string`
- `link_target_evidence_id: string`
- `link_type: enum {supports, contradicts, contextual}`
- `link_strength: float (0..1)`
- `deduction_confidence: float (0..1)`
- `deduction_locked: bool`

### Взлом (стиль Deus Ex-подобной инфильтрации)
- `hack_network_seed: int`
- `hack_entry_node_id: string`
- `hack_target_node_id: string`
- `hack_nodes_total: int`
- `hack_nodes_captured: int`
- `hack_detection_meter: float (0..100)`
- `hack_trace_speed: float`
- `hack_stealth_power: float`
- `hack_exploit_count: int`
- `hack_overclock_charges: int`
- `hack_alarm_triggered: bool`
- `hack_reward_data_packets: int`

### Диалоги и допросы
- `npc_trust[player_id][npc_id]: float (-100..100)`
- `npc_fear[player_id][npc_id]: float (0..100)`
- `npc_lie_probability[npc_id]: float (0..1)`
- `interrogation_pressure: float (0..100)`
- `interrogation_mistakes: int`
- `statement_consistency_score: float (0..1)`

### Судебная фаза
- `trial_argument_points: int`
- `trial_combo_multiplier: float`
- `trial_momentum: float (-1..1)`
- `trial_misfire_count: int`
- `trial_verdict_confidence: float (0..1)`
- `trial_outcome: enum {acquittal, mistrial, guilty_minor, guilty_true}`
