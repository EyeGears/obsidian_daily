# Код

## Цель системного слоя
Реализовать детективный геймплей в стиле «сетевая инфильтрация + анализ улик»: игрок взламывает цифровые узлы, собирает фрагменты данных и строит доказательные цепочки для обвинения.

## Основные системы
1. **Investigation Loop**
   - Осмотр сцены
   - Сбор улик
   - Взлом защищённых терминалов
   - Сопоставление улик в логической доске
   - Формирование обвинительного пакета
2. **Hacking Grid**
   - Узлы сети с уровнями защиты
   - Маршрутизация сигнала (ограниченный ресурс времени/фокуса)
   - Риск тревоги при ошибках
3. **Evidence Graph**
   - Улики, свидетели, таймлайн, мотивы
   - Веса достоверности
   - Противоречия и подтверждения
4. **Trial Resolver**
   - Подсчёт силы аргумента
   - Проверка на ложные выводы
   - Ветки исходов дела

## Реализация механики «Граф-Комнаты»

### 1) Генерация стартового графа дела
```pseudo
function GenerateCaseGraph(case_id, seed):
    rng = Random(seed)
    graph = CreateGraph()

    entry = graph.AddNode(type="hub", state="discovered", playerBuilt=false)
    core  = graph.AddNode(type="archive", state="hidden", playerBuilt=false)

    graph.Connect(entry, core, locked=true)

    // сюжетные узлы
    for t in ["witness", "timer", "lock"]:
        n = graph.AddNode(type=t, state="hidden", playerBuilt=false)
        graph.Connect(entry, n)
        graph.Connect(n, core)

    // процедурные узлы
    for i in range(0, rng.Int(3, 6)):
        t = rng.Pick(["echo", "mirror", "archive"])
        n = graph.AddNode(type=t, state="hidden", playerBuilt=false)
        graph.Connect(n, rng.Pick(graph.Nodes()))

    EnsurePath(graph, entry, core)
    return graph
```

### 2) Постройка комнат игроком
```pseudo
function TryBuildRoom(player, graph, targetNodeId, roomType):
    if not IsAdjacentToDiscovered(graph, targetNodeId):
        return Fail("build_not_adjacent")

    if roomType is rare and player.lastBuiltWasRare:
        return Fail("rare_chain_blocked")

    if not HasToken(player, roomType):
        return Fail("missing_token")

    snapshot = graph.Clone()
    newNode = graph.AddNode(type=roomType, state="hidden", playerBuilt=true)
    graph.Connect(targetNodeId, newNode.id)

    if not PathExists(graph, graph.entry, graph.core):
        graph = snapshot
        return Fail("path_broken")

    ConsumeToken(player, roomType)
    player.graph_build_actions_used += 1
    if player.graph_build_actions_used % 3 == 0:
        case_heat_level += 0.07

    return Success(newNode.id)
```

### 3) Добыча улики в комнате
```pseudo
function ResolveRoomSearch(player, room, actionType):
    base = ActionBase(actionType)
    skill = SkillBonus(player, actionType)
    roomMod = RoomModifier(room.type, actionType)
    stressPenalty = player.player_stress * 0.15

    clueScore = base + skill + roomMod - stressPenalty

    if RollPercent() <= clueScore:
        clue = SpawnClue(room.type)
        AddEvidence(clue)
        room.state = "cleared"
        return Success(clue)
    else:
        ApplyRoomFailEffect(room)
        return Fail("no_clue")
```

### 4) Соединение улик (доска доказательств)
```pseudo
function LinkEvidence(e1, e2, linkType):
    strength = CalcLinkStrength(e1, e2, linkType)
    AddLink(e1.id, e2.id, linkType, strength)

    if CreatesContradiction(e1, e2, linkType):
        case_false_leads_count += 1

    chains = FindValidChains(minLen=3, minStrength=0.55)
    if chains.count > 0:
        deduction_confidence += 0.05 * chains.count
        UnlockInsight(chains[0])
```
