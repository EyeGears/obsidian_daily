# Дела для игры

Набор запутанных убийств в духе Данганронпы: каждое дело построено так, чтобы игрок сначала получал убедительную, но ложную картину, а затем ломал её через таймлайн, противоречия, микродетали и скрытые правила локации.

## Общие правила сложности

- В каждом деле есть минимум две правдоподобные ложные версии.
- Улики должны объяснять не только «кто убил», но и «почему игрок почти поверил в другого».
- Важные подсказки нельзя прятать в одном месте: каждая ключевая догадка должна иметь 2–3 слабых сигнала.
- Главная загадка дела не должна решаться по мотиву; мотив нужен только после восстановления механики преступления.
