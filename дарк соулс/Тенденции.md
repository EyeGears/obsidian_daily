# 🌗 Тенденция региона (Region Tendency System)

---

## 🎯 Суть

**Тенденция** — это показатель “светлого” или “тёмного” состояния региона,  
зависящий от поступков игрока (убийства врагов, смерти, помощь NPC, поиск секретов и т. д.).

Она изменяет:

- поведение врагов,
    
- доступность путей и событий,
    
- визуальные и звуковые эффекты,
    
- сложность боя,
    
- даже возможные концовки региона.
    

---

## ⚖️ Основная идея

Каждый регион имеет **текущее состояние тенденции** по шкале:

`[Dark] —───◉────── [Neutral] ────────◉────── [Light]`

Например, значение от **-100 до +100**.

---

## 🧩 Структура данных в RegionController

`var tendency : float = 0.0  # от -100 (тёмная) до +100 (светлая) var tendency_state : String = "neutral"  # "dark", "neutral", "light" var tendency_history : Array = []  # лог изменений`

---

## 🔁 Логика обновления тенденции

Тенденция изменяется в зависимости от действий игрока:

|Событие|Изменение тенденции|
|---|---|
|Победа над мини-боссом|+15|
|Победа над главным боссом|+25|
|Смерть игрока|-10|
|Убийство дружественного NPC|-30|
|Спасение NPC / квест|+20|
|Использование “тёмных артефактов”|-15|
|Очистка зоны без получения урона|+10|
|Переход в “тень мира” / смерть слишком часто|-25|

---

## 🧠 Функции в RegionController

`func update_tendency(value: float, reason: String):     tendency = clamp(tendency + value, -100, 100)     tendency_history.append({"change": value, "reason": reason, "time": OS.get_ticks_msec()})     _update_tendency_state()  func _update_tendency_state():     if tendency <= -50:         tendency_state = "dark"         apply_dark_effects()     elif tendency >= 50:         tendency_state = "light"         apply_light_effects()     else:         tendency_state = "neutral"         apply_neutral_effects()`

---

## 🕯️ Влияние на мир

|Компонент|Изменение при "Dark"|Изменение при "Light"|
|---|---|---|
|**Окружение**|Туман, трещины, красные акценты, разрушенные алтари|Мягкое освещение, растения, свечения|
|**Враги**|Более агрессивные, больше урона, реже дропают хил|Менее агрессивные, дают больше энергии|
|**NPC**|Некоторые уходят или нападают|Появляются торговцы, дающие бонусы|
|**Музыка**|Мрачные синтетические аккорды|Светлые мелодические темы|
|**Лут / тайники**|Тёмные артефакты, редкие ресурсы|Чистые кристаллы, ключевые предметы|
|**Зоны / пути**|Появляются “тёмные порталы”, опасные сектора|Открываются храмы, безопасные пути|
|**Босс**|Меняется поведение, фазы и даже атаки|Может иметь упрощённую форму или альтернативный диалог|

---

## 🕹️ Взаимодействие с игроком

Тенденция может:

- **отображаться в интерфейсе региона** (свет / тень на карте),
    
- **влиять на визуальный ореол персонажа** (цвет плаща, отблеск),
    
- **изменять диалоги** с NPC,
    
- **давать альтернативные концовки** при очистке региона.
    

---

## 🧬 Встраивание в структуру мира

Добавляем поле `tendency` в **WorldState**:

`var world_state = {     "regions": {         "north": {             "boss_defeated": true,             "tendency": 45,             "tendency_state": "light"         },         "east": {             "boss_defeated": false,             "tendency": -30,             "tendency_state": "dark"         }     } }`

---

## 🧱 Интеграция с системами

|Система|Реакция на тенденцию|
|---|---|
|**CombatManager**|Изменяет урон и ИИ врагов|
|**EnvironmentManager**|Меняет палитру, освещение, эффекты частиц|
|**AudioManager**|Переключает треки и амбиент|
|**LootManager**|Меняет вероятности выпадения предметов|
|**QuestManager**|Активирует / блокирует квесты|
|**RegionController**|Управляет визуальным состоянием региона при загрузке|

---

## 🌌 Пример сценария

Игрок входит в Северный регион.

- Сначала тенденция **нейтральная** (0).
    
- Он **умирает несколько раз подряд** — тенденция падает до **-35**.  
    → Мир темнеет, враги начинают атаковать первыми.
    
- Игрок побеждает босса без смертей → +25.  
    → Мир возвращается в **светлое состояние**, NPC снова появляются в святилище.
    

---

## 🎨 Визуализация в игре

Можно реализовать через глобальные шейдеры или ColorRect-оверлеи:

|Состояние|Цветовая схема|
|---|---|
|Dark|Холодный фиолетово-красный, низкая насыщенность|
|Neutral|Сбалансированная, естественная|
|Light|Тёплый голубовато-золотой, высокая яркость|

---

## 🪶 Геймдизайнерский смысл

Тенденция региона:

- делает **мир “живым” и реагирующим** на игрока,
    
- создаёт **персонализированный ритм прогрессии**,
    
- усиливает **повторное прохождение** (в зависимости от состояния),
    
- и позволяет связывать моральные/сюжетные решения с геймплеем.
