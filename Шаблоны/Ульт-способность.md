| Название    | Действие                                                                |
| ----------- | ----------------------------------------------------------------------- |
| Черная дыра | Запускает черную дыру, что стягивает всех врагов вокруг.                |
| Ядерный щит | Запускает щит, который защищает игрока от получаемого урона.            |
| Турель      | Создает турель, что атакует врагов. Турель живет некоторое время        |
| Невидимость | Становится невидимым для врагов на некоторое время. Ничем не снимается. |
| Ускорение   | Ускоряет перемещение и стрельбу игрока.                                 |
