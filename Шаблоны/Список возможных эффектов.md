##  Основные циклы менеджера

### 1. **Инициализация боя**

**Триггер:**  
Игрок входит в “боевую зону” (аванпост, случайная встреча, скрипт миссии).

**Действия:**

- Отмечаются все враги внутри зоны.
- Устанавливается зона боя.
- Запускается таймер боя.

### 2. **Фаза активации врагов**

- Combat Manager определяет  максимальное количество активных врагов. Например, **2-3 врага** могут атаковать одновременно.
- Остальные враги переходят в **режим ожидания (Hold)**, двигаются по периметру или создают давление визуально.
- Активные враги получают **слоты атаки** (AttackSlot) и начинают действовать.

**Пример:**  
Если в зоне 5 врагов, активны только 2.  
Как только один погибает — слот освобождается, и следующий враг переходит в бой.

### 3. **Фаза менеджмента**

Combat Manager распределяет **временные интервалы атак**, чтобы избежать хаоса.

**Механика “Тактов боя”:**

- Каждый враг имеет **кулдаун атаки**.
- CombatManager проверяет общее “боевое окно”:
    - если враг №1 стреляет → враг №2 ждёт 1.5 сек перед своим действием.
- Это создаёт “ритм боя”.
### 4. **Фокус целей**

- Менеджер определяет, кто атакует игрока в данный момент.
    
- Если врагов слишком много — часть из них выбирает другие цели при их наличии (турели, союзников, приманки). В противном случае враги создают иллюзию активности.
    
- При активации способности игрока фокус может смещаться.
    

**Пример:**  
Игрок стреляет из громкой пушки - ближайшие враги переключаются на него.  
Если игрок скрывается за рельефом, враги теряют фокус через N секунд и начинают поиск.


### 5. **Спавн и волны**

Combat Manager управляет появлением врагов в зависимости от типа боя.

**Типы спавна:**

|Тип|Поведение|
|---|---|
|**Random Encounter**|1–2 врага появляются случайно в открытом мире.|
|**Ambush (засада)**|Спавн за игроком после скрипта (в песках, в ущельях).|
|**Outpost Battle (аванпост)**|Несколько волн врагов, каждая сложнее предыдущей.|
|**Boss Arena**|Одиночная сущность, управляемая напрямую, без ротации.|

### 6. **Фаза RETREAT / CLEANUP**

- Если игрок убил всех врагов → зона очищается.
- Менеджер расставляет награды, открывает барьеры.
- При отступлении игрока — бой “замораживается”: враги переходят в `Patrol` или `Idle`.

##  AI-координация врагов

Combat Manager должен избегать хаоса.  
Для этого действует **система ролей** и **приоритетов**.

|Роль врага|Поведение|Приоритет|
|---|---|---|
|**Aggressor**|Всегда в атаке, навязывает ближний бой.|Высокий|
|**Suppressor**|Ведёт огонь с дистанции, редко приближается.|Средний|
|**Support**|Бафает союзников или спавнит миньонов.|Средний|
|**Tank**|Медленный, блокирует путь, принимает урон.|Низкий|
|**Hazard**|Создаёт зону опасности (огонь, песок, кислоту).|Контекстный|

Combat Manager следит, чтобы в бою не было двух агрессоров одновременно.  
→ Один нападает, другой ждёт 2–3 секунды.  
→ Если игрок уклонился — второй вступает.



##  Дополнительные механики

###  Ротация врагов

Если бой длится долго, Combat Manager “меняет актёров”:

- один враг уходит в оборону, другой вступает;
- создаёт ощущение динамики и “тактов боя”.

###  Система эскалации

Чем дольше бой — тем агрессивнее AI:

- через 30 секунд: враги чаще используют спец-атаки;
- через 60 секунд: активируется поддержка (новые спавны, огонь, песчаная буря).

###  Контекстная реакция

Если игрок уничтожил 3 врагов подряд → оставшиеся враги могут **отступить**.  
Если враги убили игрока → зона помечается “усиленной” для следующего захода.
