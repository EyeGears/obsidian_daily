# 🗺️ Структура региона в игре типа _Hyper Light Drifter_

---

## 🎯 Концепция

> Регион — это **самодостаточный кластер зон**, объединённых общей темой, визуальным стилем, врагами, и механикой.  
> Он состоит из:
> 
> - **входной области**,
>     
> - **основных зон (комнат)**,
>     
> - **мини-подземелий или аренных зон**,
>     
> - **центрального события (босса или артефакта)**,
>     
> - **системы прогрессии** (двери, ключи, загадки, шорткаты).
>     

Структурно регион — это **“мини-игра” в рамках большого мира**,  
со своими подзонами, правилами и эмоциональной аркой.

## 🧱 Структура RegionController

`# RegionController.gd extends Node class_name RegionController  var region_id = "north" var current_zone : Node = null var visited_zones : Array = [] var boss_defeated : bool = false var region_state = {}  func _ready():     load_zone("entry_zone")  func load_zone(zone_name: String):     if current_zone:         current_zone.queue_free()     var zone_path = "res://regions/north/zones/%s.tscn" % zone_name     current_zone = load(zone_path).instantiate()     add_child(current_zone)     if not visited_zones.has(zone_name):         visited_zones.append(zone_name)`

## 🏗️ Компоненты региона

|Компонент|Описание|Аналог в Hyper Light Drifter|
|---|---|---|
|**Entry Zone**|Входная зона, соединённая с хабом. Учебная, знакомит с механиками региона.|Путь к северу от города|
|**Core Zones**|Основные области, где игрок исследует, сражается, решает загадки.|Ледяные долины и храмы|
|**Sub-Zones / Arenas**|Маленькие изолированные зоны для боёв или мини-ивентов.|Комнаты с артефактами|
|**Puzzle Rooms**|Содержат механические загадки, рычаги, скрытые проходы.|Лазеры, платформы|
|**Boss Area**|Финал региона. Уникальный босс и кат-сцена.|Храм стража региона|
|**Reward / Shrine**|Место получения фрагмента ядра или апгрейда.|Кристалл силы|
|**Shortcuts**|Обратные переходы в EntryZone.|Телепорты или лифты|

## 🧩 Состав одной зоны региона

`Zone (Node2D) ├── TileMap (geometry) ├── Enemies ├── Props ├── InteractiveObjects (рычаги, двери) ├── AreaTransition (переходы) ├── CombatManager ├── PuzzleManager (если нужно) └── ZoneScript.gd`

---

## ⚙️ Логика переходов между зонами

Каждая зона имеет **AreaTransition** — она сообщает RegionController, куда двигаться дальше:

`# внутри AreaTransition.gd func _on_body_entered(body):     if body.is_in_group("player"):         get_parent().get_parent().load_zone(target_zone)`

---

## 🧠 Прогрессия внутри региона

Прогресс игрока хранится в `region_state`:

`region_state = {     "visited_zones": ["entry_zone", "frozen_valley"],     "puzzles_solved": ["shrine_switch"],     "boss_defeated": false,     "secrets_found": 3 }`

Когда игрок побеждает босса:

- обновляется состояние региона,
    
- открывается путь в новый сектор на мировой карте,
    
- активируется глобальный флаг (например, `north_core_activated = true`).

## 🔄 Взаимодействие с глобальным миром

|Элемент|Как связан|
|---|---|
|**WorldManager**|Подгружает RegionController, когда игрок входит в регион.|
|**WorldState**|Сохраняет региональное состояние.|
|**AudioManager**|Меняет треки и амбиенты по теме региона.|
|**UI / Map**|Обновляет карту мира (открытые зоны).|

## 💫 Итог

**Регион в Hyper Light Drifter — это “мини-мир”** с собственной:

- топологией (сеткой зон),
    
- механикой (боевая и исследовательская),
    
- визуальной и музыкальной идентичностью,
    
- прогрессией (путь → награда → выход).
    

Вся структура строится на **модульности и переиспользовании**,  
что позволяет легко добавлять новые регионы, не переписывая логику ядра.
