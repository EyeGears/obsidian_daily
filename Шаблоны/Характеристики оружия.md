Виды используемых боеприпасов стандартного оружия:
- [[Энергетическое.]]
- [[Дробовики.]]
- [[Штурмовое.]]
- [[Ракетное.]]
- [[Бесконечные.]]

Эффекты боеприпасов по умолчанию.
- Патроны для штурмового оружия. Эффективнее наносят урон по слабым точкам врагов.
- Патроны для дробовика. Выше шанс оглушить цель при стрельбе в упор.
- Патроны для энергетического оружия. Эффективнее снимает щиты с врагов.
- Ракеты. Самые эффективные, но дороже всех + медленно летят.

Дополнительные виды эффектов, которые создаются оружием:

- **Электричество** - накладывает на врага статус "Электричество". Выстрелы со статусом "Электричество" имеют шанс перескочить на следующего врага.
- **Огонь** - накладывает на врага статус "Огонь". Враги со статусом "Огонь" постепенно теряют урон.
- **Взрыв** - создает оглушающие взрывы, что могут нанести больше урона врагу и постепенно приводят врага к стану.
